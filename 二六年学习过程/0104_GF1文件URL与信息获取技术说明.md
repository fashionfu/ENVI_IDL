## 一、代码概述

### 1.1 功能描述

`GSF_GF1_GetFileURL` 是一个用于获取高分一号（GF-1）PMS数据文件URL与信息的ENVI Task模块。该模块基于成熟的 `GSF_GetFileURL` 核心功能，针对GF1-PMS数据进行了优化封装，用于生成预览图、地图范围、图例和ZIP压缩包等输出信息。

**核心特点**：
- **多种显示方式**：支持RGB显示、灰度显示、分类显示、密度分割显示
- **多格式支持**：支持栅格和矢量文件输入
- **地图类型**：支持map（地图坐标）、wgs84（WGS84经纬度）、web（Web墨卡托）三种地图类型
- **输出信息丰富**：可生成PNG预览图URL、地图范围、图例PNG URL、ZIP压缩包URL等
- **灵活配置**：支持多种显示参数配置（波段组合、拉伸、颜色表等）

### 1.2 实际功能实现

根据代码逻辑分析，本模块能够实现以下**实际功能**：

#### 1.2.1 图像预览图生成
- **功能**：将高分一号PMS栅格数据转换为PNG格式的预览图
- **特点**：
  - 自动缩放：根据原始图像大小自动计算缩放因子（最大宽度800像素）
  - 波段组合：支持自定义波段组合（如真彩色[2,1,0]、假彩色[3,2,1]）
  - 图像增强：支持线性拉伸、密度分割等图像增强处理
  - 输出格式：生成PNG格式图像，返回可访问的URL地址
- **应用场景**：
  - Web端数据浏览和预览
  - 数据目录缩略图生成
  - 移动端快速查看

#### 1.2.2 地图范围信息提取
- **功能**：提取栅格数据的地理范围信息（边界框坐标）
- **支持坐标系**：
  - **wgs84**：WGS84地理坐标系（经纬度），格式：`[min_lon, min_lat, max_lon, max_lat]`
  - **web**：Web墨卡托投影坐标系，格式：`[min_x, min_y, max_x, max_y]`

- **应用场景**：
  - Web地图服务中的图层定位
  - GIS系统中的空间范围查询
  - 多源数据空间叠加分析

- **功能**：为分类结果或密度分割图像生成对应的图例PNG图像
- **适用条件**：
  - 分类显示（class_ranges和class_colors参数）

- **应用场景**：

#### 1.3.3 关键技术实现细节

**1. 自动缩放算法**
```idl
factor = 800.0D / (input_raster.NCOLUMNS) < 1
IF factor EQ 1 THEN factor = !NULL
```
- **目的**：确保预览图宽度不超过800像素，适合Web显示
- **算法**：计算缩放因子，如果原图宽度≤800，则不缩放
- **优势**：自动优化，无需手动指定尺寸

**2. 波段自动选择逻辑**
```idl
CASE input_raster.nbands OF
  1: bands = [0]
  2: bands = [0]
  3: bands = [0,1,2]
  ELSE: bands = [2,1,0]
ENDCASE
```
- **智能默认**：根据波段数自动选择最佳显示组合
- **GF1优化**：4波段默认使用[2,1,0]（真彩色），适合GF1-PMS数据

**3. 数据忽略值处理**
```idl
IF input_raster.METADATA.hasTag('data ignore value') THEN 
  data_ignore_value = input_raster.METADATA['data ignore value']
```
- **自动提取**：从栅格元数据中自动提取忽略值
- **透明处理**：忽略值像素在PNG中显示为透明

**4. 分类图像特殊处理**
```idl
; 处理全0颜色表（设为白色）
zeroIdx = WHERE(TOTAL(rgb_table,1) EQ 0)
IF zeroIdx[0] NE -1 THEN rgb_table[*, zeroIdx]=255B

; 处理Masked和Unclassified类（设为白色透明）
zeroIdx = WHERE(class_names.Contains('Masked',/fold_case))
IF zeroIdx[0] NE -1 THEN rgb_table[*, zeroIdx]=255B
```
- **背景处理**：将背景类设为白色，PNG中显示为透明
- **未分类处理**：Masked和Unclassified类也设为白色透明

**5. 密度分割颜色表生成**
```idl
; 创建颜色表
RGB_TABLE = BYTARR(3, number_of_ranges)
; 应用颜色表名称（如Rainbow）
RGB_TABLE = COL_TABLE(color_table_name, number_of_ranges)
; 反转颜色表（如果需要）
IF reverse_color_table THEN RGB_TABLE = REVERSE(RGB_TABLE, 2)
```
- **动态生成**：根据number_of_ranges动态生成颜色表
- **颜色表支持**：支持IDL内置颜色表（Rainbow、Grayscale等）
- **反转支持**：支持颜色表反转

**6. 坐标系统转换**
```idl
spatialRef1.ConvertFileToMap(FileX, FileY, MapX, MapY)
; 根据map_type进行坐标转换
CASE map_type OF
  'wgs84': ; 转换为WGS84经纬度
  'web':   ; 转换为Web墨卡托
  'map':   ; 保持原始坐标
ENDCASE
```
- **多坐标系支持**：支持三种常用坐标系
- **自动转换**：根据map_type自动进行坐标转换

## 七、技术细节

### 7.1 ENVI Task集成

**任务定义文件** (`GSF_GF1_GetFileURL.task`):
- 使用 `ENVITaskFromProcedure` 基类
- 参数类型丰富：`ENVIRaster`、`ENVIVector`、`intArray`、`bool`、`string`、`hash`等

- `map_type` 为必需参数，但有默认值 `"wgs84"`

### 7.2 输出信息结构

**out_options哈希表包含**:
- `PngFileURL`: PNG预览图URL（如果 `get_pngfile_url=1`）
- `MapExtent`: 地图范围信息（如果 `get_map_extent=1`）
- `LegendPngURL`: 图例PNG URL（如果 `get_legend_url=1`）
- `ZipFileURL`: ZIP压缩包URL（如果 `get_zipfile_url=1`）

**MapExtent格式**（根据map_type不同）:
- `wgs84`: `[min_lon, min_lat, max_lon, max_lat]`
- `web`: `[min_x, min_y, max_x, max_y]`（Web墨卡托坐标）
- `map`: 原始地图坐标

### 7.3 波段组合说明

**GF1-PMS波段配置**:
- B1 (蓝, 索引0): 450-520 nm
- B2 (绿, 索引1): 520-590 nm
- B3 (红, 索引2): 630-690 nm
- B4 (近红外, 索引3): 770-890 nm

**常用波段组合**:
- 真彩色: `[2, 1, 0]` (红、绿、蓝)
- 假彩色: `[3, 2, 1]` (近红外、红、绿)
- 单波段: `[0]` 或 `[1]` 或 `[2]` 或 `[3]`

## 十、常见问题与解决

### Q1: 生成的PNG预览图质量不佳

**可能原因**:
1. 拉伸参数设置不当
2. 波段组合选择不合适
3. 数据值范围异常

**解决方案**:
1. 调整 `linear_percent` 参数
2. 尝试不同的波段组合
3. 检查数据值范围

### Q2: 地图范围不正确

**可能原因**:
1. 输入数据缺少空间参考信息
2. 地图类型选择错误

**解决方案**:
1. 确保输入数据具有正确的空间参考
2. 根据应用场景选择合适的地图类型

### Q3: ZIP压缩包生成失败

**可能原因**:
1. 文件路径过长
2. 磁盘空间不足
3. 文件权限问题

**解决方案**:
1. 使用较短的路径
2. 检查磁盘空间
3. 检查文件权限
