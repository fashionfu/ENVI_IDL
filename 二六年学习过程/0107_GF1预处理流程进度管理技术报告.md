## 概述

### 功能描述

本模块实现了高分一号（GF1）卫星影像的完整预处理流程，包括辐射定标、FLAASH大气校正和RPC正射校正三个步骤。该模块使用`GSF_Progress_Message`类管理整个处理过程的进度显示，提供详细的进度信息和错误处理机制。

### 主要特性

- ✅ **完整预处理流程**：集成辐射定标、FLAASH大气校正和RPC正射校正三个步骤
- ✅ **灵活步骤控制**：支持启用/禁用各个处理步骤，灵活配置处理流程
- ✅ **进度消息管理**：使用`GSF_Progress_Message`类统一管理进度显示
- ✅ **错误处理机制**：完善的错误处理和SPAWN错误抑制机制
- ✅ **对象生命周期管理**：自动管理Raster对象的生命周期，确保对象有效性
- ✅ **临时文件管理**：自动清理临时文件，避免磁盘空间浪费
- ✅ **多格式输出**：支持ENVI和TIFF格式输出
- ✅ **附加功能**：自动生成预览图、ZIP压缩包和地图范围信息
- ✅ **调试信息**：详细的调试信息输出，便于问题排查

#### 阶段1：初始化与参数设置

```idl
; 关键代码片段
; 初始化进度消息管理器
gsf_progress = GSF_Progress_Message()
IF OBJ_VALID(gsf_progress) THEN BEGIN
  gsf_progress.SetProgress, percent=0, message='初始化预处理流程...'
ENDIF

; 设置默认值
IF ~KEYWORD_SET(enable_radiometric) THEN enable_radiometric = 1
IF ~KEYWORD_SET(enable_flaash) THEN enable_flaash = 1
IF ~KEYWORD_SET(enable_rpc) THEN enable_rpc = 1
IF ~KEYWORD_SET(visibility) THEN visibility = 40.0
IF ~KEYWORD_SET(aerosol_model) THEN aerosol_model = 'Rural'
IF ~KEYWORD_SET(sensor_type) THEN sensor_type = 'GF1-PMS'
IF ~KEYWORD_SET(resampling) THEN resampling = 'Bilinear'
IF ~KEYWORD_SET(output_format) THEN output_format = 'ENVI'
IF ~KEYWORD_SET(get_out_options) THEN get_out_options = 1

; 验证输入文件
IF ~KEYWORD_SET(input_file) OR (input_file EQ '') THEN BEGIN
  e.ReportError, '错误: 必须提供输入文件路径'
  IF OBJ_VALID(gsf_progress) THEN gsf_progress.Finish
  RETURN
ENDIF
```

**功能**：
- 创建`GSF_Progress_Message`对象，用于管理进度显示
- 设置默认参数值（步骤启用状态、能见度、气溶胶模型等）
- 验证输入文件存在性和有效性
- 处理ENVIURI对象，提取文件路径字符串

#### 阶段3：步骤1 - 辐射定标（可选）

; 关键代码片段
IF enable_radiometric THEN BEGIN
  current_step = current_step + 1
  percent = ROUND((current_step * 100.0) / (total_steps + 1))
  step_message = '步骤' + STRING(current_step) + '/' + STRING(total_steps) + ': 开始辐射定标处理...'
  
  IF OBJ_VALID(gsf_progress) THEN BEGIN

    input_file=current_input, $

    output_path=output_path, $
    get_out_options=0, $
    output_raster=current_output, $

      gsf_progress.SetProgress, percent=percent+8, message='✓ 辐射定标完成: ' + output_filename

#### 阶段4：步骤2 - FLAASH大气校正（可选）

```idl
; 关键代码片段
IF enable_flaash THEN BEGIN
  current_step = current_step + 1
  percent = ROUND((current_step * 100.0) / (total_steps + 1))
  step_message = '步骤' + STRING(current_step) + '/' + STRING(total_steps) + ': 开始FLAASH大气校正处理...'
  
  IF OBJ_VALID(gsf_progress) THEN BEGIN
    gsf_progress.SetProgress, percent=percent, message=step_message
  ENDIF
  
  ; 调用FLAASH任务，捕获可能的spawn错误
  CATCH, flaash_call_err
  IF flaash_call_err EQ 0 THEN BEGIN
    GSF_GF1_FLAASH_AtmosphericCorrection, $
      input_file=current_input, $
      visibility=visibility, $
      aerosol_model=aerosol_model, $
      output_format=output_format, $
      output_path=output_path, $
      get_out_options=0, $
      output_raster=current_output, $
      output_file=current_output_file
    CATCH, /CANCEL
  ENDIF ELSE BEGIN
    CATCH, /CANCEL
    ; 检查是否是spawn错误
    flaash_error_msg = !ERROR_STATE.MSG
    IF (STRPOS(STRUPCASE(flaash_error_msg), 'SPAWN') GE 0) THEN BEGIN
      MESSAGE, /RESET  ;清除错误消息，抑制弹窗
      ; spawn错误通常不影响主要功能，检查是否有输出
      IF OBJ_VALID(current_output) THEN BEGIN
        ; 继续执行，不返回错误
      ENDIF ELSE BEGIN
        e.ReportError, '错误: FLAASH大气校正执行失败 (SPAWN错误): ' + flaash_error_msg
        RETURN
      ENDELSE
    ENDIF ELSE BEGIN
      e.ReportError, '错误: FLAASH大气校正执行失败: ' + flaash_error_msg
      RETURN
    ENDELSE
  ENDELSE
  
  ; 如果current_output无效，但current_output_file有效，尝试重新打开
  IF ~OBJ_VALID(current_output) THEN BEGIN
    IF KEYWORD_SET(current_output_file) AND (current_output_file NE '') THEN BEGIN
      current_output = e.OpenRaster(current_output_file)
    ENDIF
  ENDIF
  
  ; 检查输出有效性并更新输入输出变量
  IF OBJ_VALID(current_output) THEN BEGIN
    current_input = current_output_file
    temp_files.Add, current_output_file
    IF OBJ_VALID(gsf_progress) THEN BEGIN
      output_filename = FILE_BASENAME(current_output_file)
      gsf_progress.SetProgress, percent=percent+8, message='✓ FLAASH大气校正完成: ' + output_filename
    ENDIF
  ENDIF ELSE BEGIN
    e.ReportError, '错误: FLAASH大气校正失败'
    RETURN
  ENDELSE
ENDIF
```

**功能**：
- 检查是否启用FLAASH大气校正步骤
- 更新进度消息，显示当前步骤信息
- 调用`GSF_GF1_FLAASH_AtmosphericCorrection`任务
- **SPAWN错误处理**：捕获并抑制SPAWN错误弹窗，检查输出有效性
- **对象生命周期管理**：如果`current_output`无效，从`current_output_file`重新打开
- 检查输出有效性，更新输入输出变量
- 更新进度消息，显示完成信息

**SPAWN错误处理机制**：
- SPAWN错误通常不影响主要功能，只是ENVI内部的一个警告
- 使用`MESSAGE, /RESET`抑制错误弹窗
- 检查任务输出是否有效，如果有效则继续执行
- 如果输出无效，才报告错误并终止处理

### 2. SPAWN错误抑制机制

**问题**：FLAASH任务执行时可能出现SPAWN错误弹窗，影响用户体验

**解决方案**：

```idl
; 调用FLAASH任务，捕获可能的spawn错误
CATCH, flaash_call_err
IF flaash_call_err EQ 0 THEN BEGIN
  GSF_GF1_FLAASH_AtmosphericCorrection, ...
  CATCH, /CANCEL
ENDIF ELSE BEGIN
  CATCH, /CANCEL
  flaash_error_msg = !ERROR_STATE.MSG
  IF (STRPOS(STRUPCASE(flaash_error_msg), 'SPAWN') GE 0) THEN BEGIN
    MESSAGE, /RESET  ;清除错误消息，抑制弹窗
    ; spawn错误通常不影响主要功能，检查是否有输出
    IF OBJ_VALID(current_output) THEN BEGIN
      ; 继续执行，不返回错误
    ENDIF ELSE BEGIN
      e.ReportError, '错误: FLAASH大气校正执行失败 (SPAWN错误): ' + flaash_error_msg
      RETURN
    ENDELSE
  ENDIF ELSE BEGIN
    e.ReportError, '错误: FLAASH大气校正执行失败: ' + flaash_error_msg
    RETURN
  ENDELSE
ENDELSE
```

**效果**：
- ✅ 抑制SPAWN错误弹窗
- ✅ 检查任务输出有效性
- ✅ 如果输出有效，继续执行
- ✅ 如果输出无效，才报告错误

**为什么需要抑制SPAWN错误？**
- SPAWN错误通常是ENVI内部的一个警告，不影响主要功能
- 错误弹窗会影响用户体验，特别是在批量处理时
- 通过检查任务输出有效性，可以判断任务是否真正失败

### 3. Raster对象生命周期管理

**问题**：在执行过程中，Raster对象可能失效，导致后续步骤失败

**解决方案**：

```idl
; 如果current_output无效，但current_output_file有效，尝试重新打开
IF ~OBJ_VALID(current_output) THEN BEGIN
  IF KEYWORD_SET(current_output_file) AND (current_output_file NE '') THEN BEGIN
    PRINT, 'DEBUG[PROGRESS]: current_output无效，尝试从current_output_file重新打开raster...'
    CATCH, reopen_err
    IF (reopen_err EQ 0) THEN BEGIN
      current_output = e.OpenRaster(current_output_file)
      CATCH, /CANCEL
      IF OBJ_VALID(current_output) THEN BEGIN
        PRINT, 'DEBUG[PROGRESS]: 成功重新打开raster: ', current_output_file
      ENDIF ELSE BEGIN
        PRINT, 'DEBUG[PROGRESS]: 重新打开raster失败'
      ENDELSE
    ENDIF ELSE BEGIN
      CATCH, /CANCEL
      PRINT, 'DEBUG[PROGRESS]: 重新打开raster时出错: ', !ERROR_STATE.MSG
    ENDELSE
  ENDIF
ENDIF
```

**效果**：
- ✅ 自动检测Raster对象有效性
- ✅ 如果无效，从文件路径重新打开
- ✅ 确保Raster对象始终有效
- ✅ 提高代码的健壮性

**为什么Raster对象会失效？**
- 某些操作（如`GSF_GetFileURL`）可能会关闭Raster对象
- 虚拟栅格对象在某些情况下可能失效
- 通过重新打开文件，可以恢复Raster对象

### 常见问题解答

#### Q1: 如何跳过某个处理步骤？

**A**: 设置对应的`enable_*`参数为0。例如，跳过FLAASH大气校正：
```idl
Task.ENABLE_FLAASH = 0
```

#### Q2: SPAWN错误会影响处理结果吗？

**A**: 通常不会。SPAWN错误通常是ENVI内部的一个警告，不影响主要功能。系统会自动检查任务输出有效性，如果输出有效则继续执行。

#### Q3: 如何处理Raster对象失效问题？

**A**: 系统会自动检测Raster对象有效性，如果无效，会从文件路径重新打开。无需手动处理。

#### Q4: 临时文件会被自动清理吗？

**A**: 是的。处理完成后，系统会自动清理临时文件。如果需要保留临时文件，可以设置`keep_temp_files`参数。

#### Q5: 如何查看处理进度？

**A**: 系统会通过`GSF_Progress_Message`类显示详细的进度信息，包括进度百分比和当前步骤信息。

### H. 常见错误及解决方案

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| "必须提供输入文件路径" | 输入文件参数未设置 | 检查输入文件参数是否正确设置 |
| "输入文件不存在" | 文件路径错误或文件不存在 | 检查文件路径，确保文件存在 |
| "辐射定标失败" | 辐射定标任务执行失败 | 检查输入文件、参数设置。查看错误日志获取详细信息 |
| "FLAASH大气校正执行失败 (SPAWN错误)" | FLAASH任务执行失败且无有效输出 | 检查输入数据、参数设置。查看错误日志获取详细信息 |
| "RPC正射校正失败" | RPC正射校正任务执行失败 | 检查输入数据、参数设置。查看错误日志获取详细信息 |
| "内存不足" | 系统内存不足 | 关闭其他程序，确保有足够内存（建议16GB以上） |
| "磁盘空间不足" | 磁盘空间不足 | 清理磁盘空间，确保有足够空间（建议至少100GB） |
