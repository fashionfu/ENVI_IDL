## 一、代码概述

### 1.1 功能描述

`GSF_GF1_ChlorophyllA` 是一个用于计算高分一号（GF-1）PMS数据叶绿素a浓度的ENVI Task模块。该模块实现了两种算法：
- **蓝绿波段比值算法（Blue-Green Ratio）**：基于哨兵2A公式，适用于大多数水体
- **三波段算法（Three-Band Algorithm）**：基于Gitelson等（2008）的方法，适用于高叶绿素a浓度水体

#### 2.4.1 波段编号说明

**GF1-PMS波段配置**:
- B1(蓝, 索引0) → PixelwiseBandMathRaster中的 `b1`
- B2(绿, 索引1) → PixelwiseBandMathRaster中的 `b2`
- B3(红, 索引2) → PixelwiseBandMathRaster中的 `b3`
- B4(近红外, 索引3) → PixelwiseBandMathRaster中的 `b4`

**注意**: `PixelwiseBandMathRaster` 使用 `b1, b2, b3...` 表示波段，索引从1开始（不是0）。

#### 2.4.2 算法1：蓝绿波段比值算法

**位置**: 第218-253行

**公式**:
```
Chl-a = 4.089 * (b3/b2)^2 - 0.746 * (b3/b2) + 29.733
```
其中：
- `b2` = 绿波段(B2)
- `b3` = 红波段(B3)

**实现方式**:
```idl
expression = '4.089*(FLOAT(b3)/FLOAT(b2))^2 - 0.746*(FLOAT(b3)/FLOAT(b2)) + 29.733'

chlaTask = ENVITask('PixelwiseBandMathRaster')
chlaTask.INPUT_RASTER = Raster
chlaTask.EXPRESSION = expression
chlaTask.Execute
ChlARaster = chlaTask.OUTPUT_RASTER
```

**关键点**:
- 使用 `ENVITask('PixelwiseBandMathRaster')` 而不是 `ENVIPixelwiseBandMathRaster` 函数
- 直接使用整个 `Raster` 对象，不需要先提取子波段
- 使用 `FLOAT()` 确保浮点运算精度

#### 2.4.3 算法2：三波段算法

**位置**: 第255-292行

**公式**:
```
Chl-a = [(1/RED - 1/NIR) * NIR] * calibration_coefficient
```

**实现方式**:

```idl
expression = '((1.0/FLOAT(b3) - 1.0/FLOAT(b4)) * FLOAT(b4)) * ' + calCoeffStr

```

**关键点**:
- 使用条件表达式避免除零错误
- 无效值设置为 `-999.0`

## 四、算法详细说明

### 4.1 蓝绿波段比值算法

**理论基础**: 基于哨兵2A的叶绿素a反演公式

**公式推导**:
- 原始公式（哨兵2A）: `CHLA = 4.089*(b4/b3)^2 - 0.746*(b4/b3) + 29.733`
  - 其中 `b4` = 红波段, `b3` = 绿波段
- 转换为GF1-PMS: `CHLA = 4.089*(b3/b2)^2 - 0.746*(b3/b2) + 29.733`
  - 其中 `b3` = 红波段(B3), `b2` = 绿波段(B2)

**适用场景**:
- 清洁水体
- 悬浮物含量较低的水体
- 快速评估

**优点**:
- 计算简单快速
- 对大多数水体适用
- 不需要近红外波段

### 4.2 三波段算法

**理论基础**: Gitelson等（2008）的半分析模型

**公式**:
```
Chl-a = [(1/RED - 1/NIR) * NIR] * calibration_coefficient
```

**数学原理**:
- 利用叶绿素a在红波段和近红外波段的吸收特性
- `(1/RED - 1/NIR)` 表示叶绿素a的吸收差异
- 乘以 `NIR` 进行归一化
- 通过 `calibration_coefficient` 进行区域校准

**适用场景**:
- 富营养化水体
- 高叶绿素a浓度水体
- 需要较高精度的应用

**优点**:
- 精度较高
- 对高浓度叶绿素a敏感
- 支持区域校准

**注意事项**:
- 需要避免除零错误（代码中已处理）
- 需要近红外波段
- 建议根据实测数据校准系数
