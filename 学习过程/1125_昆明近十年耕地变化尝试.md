# 昆明近十年耕地变化监测与分析项目

## 项目概述

本项目基于Landsat 8/9卫星遥感影像数据，采用监督分类和非监督分类两种方法，对昆明市及其周边地区2014-2025年（共11年，不含2018年）的耕地变化进行监测与分析。

### 研究目标
- 监测近十年昆明市耕地面积变化趋势
- 分析耕地变化的驱动因素
- 对比监督分类与非监督分类方法的分类效果
- 为耕地保护政策制定提供科学依据

## 数据说明

### 数据源
- **卫星**：Landsat 8/9
- **产品级别**：L2级地表反射率产品（Surface Reflectance）
- **空间分辨率**：30米×30米
- **影像尺寸**：约7700×7800像素
- **覆盖面积**：约5420-5440平方公里

### 时间序列
- **研究时段**：2014-2025年（共11年）
- **缺失年份**：2018年（无数据）
- **具体年份**：2014, 2015, 2016, 2017, 2019, 2020, 2021, 2022, 2023, 2024, 2025

### 波段信息
- **原始波段**：7个（B1-B7）
  - B1: 蓝色（Blue）
  - B2: 绿色（Green）
  - B3: 红色（Red）
  - B4: 近红外（NIR）
  - B5: 短波红外1（SWIR1）
  - B6: 短波红外2（SWIR2）
  - B7: 短波红外2（SWIR2）

### 光谱指数
- **NDVI**（归一化植被指数）：(NIR - Red) / (NIR + Red)
- **NDWI**（归一化水体指数）：(Green - SWIR1) / (Green + SWIR1)
- **NDBI**（归一化建筑指数）：(SWIR1 - NIR) / (SWIR1 + NIR)

## 技术方法

### 1. 数据预处理

#### 1.1 批量堆叠处理（1121_LandsatBatch.pro）
- **功能**：批量处理Landsat 8 L2级数据，打开并组合多光谱影像
- **输入**：多个Landsat数据文件夹（包含SR_B*.TIF文件）
- **输出**：堆叠后的多光谱影像（保存到`results_batch_roi`文件夹）
- **关键步骤**：
  1. 从MTL XML文件读取空间参考信息（UTM Zone、Datum、像素大小、四角坐标）
  2. 打开7个原始波段TIF文件
  3. 为每个波段添加空间参考
  4. 使用BuildLayerStack堆叠波段
  5. 保存堆叠结果

#### 1.2 2025年数据特殊处理（1124_Landsat2025.pro）
- **功能**：重新处理2025年Landsat数据
- **输入**：`F:\TestDemo\gengdi\LC08_L2SP_129042_20250507_20250513_02_T1`
- **输出**：堆叠后的多光谱影像（保存到`results_batch_roi`文件夹）
- **特殊处理**：针对2025年数据的空间参考问题进行优化

### 2. 监督分类（随机森林）

#### 2.1 代码文件：kunming_1124.pro
- **分类方法**：随机森林（Random Forest）
- **决策树数量**：100棵
- **分类类别**：耕地、非耕地（2类）
- **输入特征**：7个原始波段 + 3种光谱指数（共10个特征）

#### 2.2 处理流程
1. **打开堆叠影像**：从`results_batch_roi`文件夹读取堆叠后的影像
2. **计算光谱指数**：计算NDVI、NDWI、NDBI
3. **合并波段**：将7个原始波段与3个光谱指数合并（共10个波段）
4. **加载ROI**：从`ROIData`文件夹加载对应年份的ROI文件（.xml格式）
5. **随机森林分类**：使用ROI样本训练分类器并执行分类
6. **后处理**：
   - 分类平滑（5×5核窗口）
   - 分类聚合（最小面积阈值）
   - 更新元数据（类别名称、颜色查找表）
7. **统计计算**：计算各类别像素数量、占比、面积（公顷、平方公里）
8. **保存结果**：保存到`gengdi_results`文件夹

#### 2.3 输出文件
- `classification_YYYY.dat`：原始分类结果
- `classification_YYYY_final.dat`：后处理后的最终结果
- `classification_statistics_YYYY.txt`：统计报告

### 3. 非监督分类（ISODATA）

#### 3.1 代码文件：gengdi_1125.pro
- **分类方法**：ISODATA（迭代自组织数据分析技术）
- **优化参数**（针对16GB内存服务器）：
  - 类别数量：18
  - 迭代次数：28
  - 最小类别大小：100像素
- **输入特征**：7个原始波段 + 3种光谱指数（共10个特征）

#### 3.2 处理流程
1. **打开或堆叠影像**：
   - 优先查找预堆叠的.dat文件
   - 如果不存在，自动从原始TIF文件堆叠
2. **计算光谱指数**：计算NDVI、NDWI、NDBI
3. **合并波段**：将7个原始波段与3个光谱指数合并
4. **ISODATA分类**：执行非监督分类，识别18个光谱类别
5. **后处理**：同监督分类
6. **统计计算**：计算各类别统计信息
7. **保存结果**：保存到`ResultData（非监督分类）`文件夹

#### 3.3 输出文件
- `isodata_classification_YYYY.dat`：原始分类结果
- `isodata_classification_YYYY_final.dat`：后处理后的最终结果
- `classification_statistics_YYYY.txt`：统计报告（包含18个类别的详细信息）

### 4. 后处理步骤

#### 4.1 分类平滑
- **方法**：ClassificationSmoothing任务
- **参数**：5×5核窗口
- **目的**：去除孤立像素，平滑分类结果

#### 4.2 分类聚合
- **方法**：ClassificationAggregation任务
- **参数**：最小面积阈值（根据空间参考自动计算，默认50像素）
- **目的**：合并小面积区域，减少碎片化

#### 4.3 元数据更新
- **类别名称**：设置类别名称（耕地、非耕地）
- **颜色查找表**：
  - 耕地：绿色（RGB: 0, 255, 0）
  - 非耕地：灰色（RGB: 128, 128, 128）

## 结果分析

### 监督分类结果（随机森林）

根据监督分类结果，近十年昆明市耕地面积变化如下：

| 年份 | 耕地面积（公顷） | 耕地面积（平方公里） | 占比（%） |
|------|----------------|-------------------|----------|
| 2014 | 253.26         | 2.53              | 0.0047   |
| 2015 | 5369.04        | 53.69             | 0.0990   |
| 2016 | 6287.94        | 62.88             | 0.1159   |
| 2017 | 2895.30        | 28.95             | 0.0534   |
| 2019 | 6463.44        | 64.63             | 0.1192   |
| 2020 | 519.93         | 5.20              | 0.0096   |
| 2021 | 80167.50       | 801.67            | 1.4771   |
| 2022 | 68685.84       | 686.86            | 1.2671   |
| 2023 | 4163.40        | 41.63             | 0.0768   |
| 2024 | 11065.68       | 110.66            | 0.2039   |
| 2025 | 930.78         | 9.31              | 0.0171   |

### 变化特征

#### 阶段一（2014-2016年）：缓慢增长期
- 耕地面积从253.26公顷增长至6287.94公顷
- 年均增长率：约3000公顷/年

#### 阶段二（2017-2020年）：波动下降期
- 耕地面积在2895.30-6463.44公顷之间波动
- 2020年降至最低点519.93公顷

#### 阶段三（2021-2022年）：快速增长期
- 2021年耕地面积达到峰值80167.50公顷（801.67平方公里）
- 2022年略有下降至68685.84公顷

#### 阶段四（2023-2025年）：快速下降期
- 耕地面积从4163.40公顷下降至930.78公顷
- 年均下降率：约1600公顷/年

### 非监督分类结果（ISODATA）

非监督分类识别出18个光谱类别，主要类别包括：
- **Class 1**：最大类别，约33%，可能为植被/林地
- **Class 11-15**：主要类别，各占约5-15%
- 其他类别：小面积类别，可能包括耕地、水体、建筑等

## 主要发现

### 1. 耕地面积波动显著
近十年昆明市耕地面积呈现明显的波动变化，从2014年的253.26公顷到2021年的峰值80167.50公顷，再到2025年的930.78公顷，变化幅度巨大。

### 2. 2021年为关键转折点
2021年耕地面积达到研究期内最高值，这可能与以下因素有关：
- 国家粮食安全政策强化
- 耕地保护政策落实
- 遥感监测技术改进，分类精度提高

### 3. 近期耕地面积下降趋势明显
2023-2025年耕地面积快速下降，这可能与以下因素有关：
- 城市化进程加快，建设用地扩张
- 生态保护政策实施，部分耕地退耕
- 农业产业结构调整

### 4. 两种分类方法对比
- **监督分类**：直接识别耕地和非耕地，结果更符合实际应用需求
- **非监督分类**：识别出18个光谱类别，提供了更细致的土地利用信息
- **结合使用**：可以更全面地了解土地利用变化

## 驱动力分析

### 自然因素
- **气候条件**：亚热带高原季风气候，四季如春，适宜农业种植
- **地形地貌**：云贵高原，地形复杂，耕地主要分布在平坝、河谷和缓坡地带

### 社会经济因素
- **城市化进程**：城市扩张导致部分耕地被占用
- **农业政策**：粮食安全政策、耕地保护政策的影响
- **产业结构调整**：农业产值在GDP中的比重下降

### 技术因素
- **遥感监测技术**：监测精度不断提高
- **农业技术**：机械化、现代化水平提高

### 生态保护因素
- **生态保护政策**：退耕还林、退耕还草政策的实施
- **环境治理**：土壤污染治理、水土保持工作

## 使用说明

### 环境要求
- **软件**：ENVI + IDL
- **内存**：建议16GB以上（非监督分类优化参数）
- **存储空间**：约50GB（原始数据 + 处理结果）

### 快速开始

1. **准备数据**：将Landsat 8/9 L2级数据解压到项目文件夹
2. **运行预处理**：执行`1121_LandsatBatch.pro`进行数据堆叠
3. **标注ROI**：在ENVI中标注耕地和非耕地区域，保存到`ROIData`文件夹
4. **运行分类**：
   - 监督分类：执行`kunming_1124.pro`
   - 非监督分类：执行`gengdi_1125.pro`
5. **查看结果**：在`gengdi_results`和`ResultData（非监督分类）`文件夹查看分类结果和统计报告

### 注意事项

1. **路径设置**：代码中的路径需要根据实际情况修改
2. **ROI文件命名**：ROI文件必须命名为`YYYY.xml`格式（如`2014.xml`）
3. **内存管理**：非监督分类参数已优化为16GB内存，可根据实际情况调整
