## 一、代码概述

### 1.1 功能描述

`GSF_GF1_EutrophicationIndex` 是一个用于计算高分一号（GF-1）PMS数据富营养化指数的ENVI Task模块。该模块实现了基于TLI（Trophic Level Index，营养状态指数）的富营养化评估方法，通过综合叶绿素a和悬浮物浓度来评估水体的富营养化程度。
![Landsat 8 地表温度反演结果](https://github.com/fashionfu/ENVI_IDL/blob/main/%E5%AD%A6%E4%B9%A0%E8%BF%87%E7%A8%8B/1114_%E6%B8%A9%E5%BA%A6%E5%8F%8D%E6%BC%94.png)
**核心特点**：
- **自动计算模式**：自动调用 `GSF_GF1_ChlorophyllA` 和 `GSF_GF1_SuspendedMatter` 计算中间参数
- **输入文件模式**：支持使用已有的叶绿素a和悬浮物浓度文件
- **TLI算法**：基于哨兵2A公式，适用于GF1-PMS数据
- **灵活配置**：支持自定义权重系数（虽然当前实现直接使用TLI公式，权重参数保留用于未来扩展）

### 2.5 富营养化指数计算（核心算法）

**位置**: 第301-350行

**关键改进**: 完全按照 `landsat9_spectral_indices.pro` 的波段运算方式实现

#### 2.5.1 波段编号说明

**GF1-PMS波段配置**:
- B1(蓝, 索引0) → PixelwiseBandMathRaster中的 `b1`
- B2(绿, 索引1) → PixelwiseBandMathRaster中的 `b2`
- B3(红, 索引2) → PixelwiseBandMathRaster中的 `b3`
- B4(近红外, 索引3) → PixelwiseBandMathRaster中的 `b4`

**注意**: `PixelwiseBandMathRaster` 使用 `b1, b2, b3...` 表示波段，索引从1开始（不是0）。

#### 2.5.2 TLI富营养化指数公式

**理论基础**: 基于哨兵2A的TLI公式，转换为GF1-PMS波段配置

**原始公式（哨兵2A）**:
```
TLI = 5.4*(2.5+1.086*alog((4.089*(b4/b3)^2-0.746*(b4/b3)+29.733)/1000.0)) + 
      4.6*(5.118+0.49*alog(119.62*(b3/b2)^6.0823))
```
其中：
- `b4` = 红波段（哨兵2A）
- `b3` = 绿波段（哨兵2A）
- `b2` = 蓝波段（哨兵2A）

**转换为GF1-PMS**:
```
TLI = 5.4*(2.5+1.086*alog((4.089*(b3/b2)^2-0.746*(b3/b2)+29.733)/1000.0)) + 
      4.6*(5.118+0.49*alog(119.62*(b2/b1)^6.0823))
```
其中：
- `b1` = 蓝波段(B1)
- `b2` = 绿波段(B2)
- `b3` = 红波段(B3)

**公式组成**:
1. **第一部分（叶绿素a部分）**:
   - `CHLA = 4.089*(b3/b2)^2 - 0.746*(b3/b2) + 29.733`
   - 权重系数：5.4
   - 对数项：`2.5+1.086*alog(CHLA/1000.0)`

2. **第二部分（悬浮物部分）**:
   - `TSS = 119.62*(b2/b1)^6.0823`
   - 权重系数：4.6
   - 对数项：`5.118+0.49*alog(TSS)`

**实现方式**:
```idl
tli_expr = '5.4*(2.5+1.086*alog((4.089*(FLOAT(b3)/FLOAT(b2))^2 - 0.746*(FLOAT(b3)/FLOAT(b2)) + 29.733)/1000.0)) + ' + $
  '4.6*(5.118+0.49*alog(119.62*(FLOAT(b2)/FLOAT(b1))^6.0823))'

eiTask = ENVITask('PixelwiseBandMathRaster')
eiTask.INPUT_RASTER = Raster
eiTask.EXPRESSION = tli_expr
eiTask.Execute
EIRaster = eiTask.OUTPUT_RASTER
```

**关键点**:
- 使用 `ENVITask('PixelwiseBandMathRaster')` 而不是 `ENVIPixelwiseBandMathRaster` 函数
- 直接使用整个 `Raster` 对象，不需要先提取子波段
- 使用 `FLOAT()` 确保浮点运算精度
- **重要**: 使用 `alog`（自然对数，以e为底），**不是** `ALOG10`（常用对数，以10为底）

## 四、算法详细说明

### 4.1 TLI富营养化指数算法

**理论基础**: 基于营养状态指数（Trophic Level Index, TLI）的综合评估方法

**TLI公式**:
```
TLI = 5.4 * TLI_CHLA + 4.6 * TLI_TSS
```

其中：
- `TLI_CHLA = 2.5 + 1.086 * alog(CHLA / 1000.0)`
- `TLI_TSS = 5.118 + 0.49 * alog(TSS)`
- `CHLA = 4.089*(b3/b2)^2 - 0.746*(b3/b2) + 29.733`（叶绿素a浓度，mg/m³）
- `TSS = 119.62*(b2/b1)^6.0823`（悬浮物浓度，mg/L）

**数学原理**:
1. **叶绿素a部分**:
   - 使用蓝绿波段比值算法计算叶绿素a浓度
   - 通过自然对数转换，将浓度值映射到TLI尺度
   - 除以1000.0进行归一化处理

2. **悬浮物部分**:
   - 使用红波段法计算悬浮物浓度
   - 通过自然对数转换，将浓度值映射到TLI尺度

3. **综合评估**:
   - 叶绿素a权重：5.4
   - 悬浮物权重：4.6
   - 总权重：10.0

**适用场景**:
- 内陆湖泊、水库
- 河流、河口区域
- 近岸海域
- 富营养化监测和评估

**优点**:
- 综合考虑叶绿素a和悬浮物两个关键指标
- 基于成熟的TLI理论
- 适用于多种水体类型
- 结果具有明确的物理意义

**注意事项**:
- 需要经过辐射校正的输入数据
- 对云、阴影等干扰敏感
- 建议结合实测数据验证
- 不同区域可能需要调整系数

### 4.2 富营养化等级划分

根据TLI值，可以划分富营养化等级：

| TLI值范围 | 营养状态 | 说明 |
|----------|---------|------|
| TLI < 30 | 贫营养（Oligotrophic） | 水质良好，营养盐含量低 |
| 30 ≤ TLI < 50 | 中营养（Mesotrophic） | 水质中等，营养盐含量适中 |
| 50 ≤ TLI < 60 | 轻度富营养（Light Eutrophic） | 开始出现富营养化迹象 |
| 60 ≤ TLI < 70 | 中度富营养（Moderate Eutrophic） | 富营养化明显，可能出现水华 |
| TLI ≥ 70 | 重度富营养（Severe Eutrophic） | 严重富营养化，水华频发 |

**注意**: 上述等级划分仅供参考，实际应用中应根据研究区域的具体情况和实测数据进行调整。

### 4.3 对数函数说明

**重要**: 代码中使用的是 `alog`（自然对数，以e为底），**不是** `ALOG10`（常用对数，以10为底）。

**区别**:
- `alog(x)`: 自然对数，ln(x)，以e（≈2.718）为底
- `ALOG10(x)`: 常用对数，log₁₀(x)，以10为底

**在TLI公式中的使用**:
- 原始TLI公式使用自然对数
- 代码实现中必须使用 `alog` 而不是 `ALOG10`
- 这是确保计算结果正确性的关键点

### 8.2 波段运算表达式

**表达式语法**:
- 使用 `b1, b2, b3...` 表示波段（从1开始）
- 使用 `FLOAT()` 确保浮点运算
- 支持数学运算符：`+`, `-`, `*`, `/`, `^`
- 支持函数：`alog`（自然对数）

**TLI表达式**:
```idl
'5.4*(2.5+1.086*alog((4.089*(FLOAT(b3)/FLOAT(b2))^2 - 0.746*(FLOAT(b3)/FLOAT(b2)) + 29.733)/1000.0)) + ' + $
'4.6*(5.118+0.49*alog(119.62*(FLOAT(b2)/FLOAT(b1))^6.0823))'
```

### 8.3 文件I/O处理

**输入文件**:
- 支持ENVI格式（`.dat/.hdr`）
- 支持TIFF格式
- 自动检测文件格式

**输出文件**:
- ENVI格式：使用 `'ENVI'` 导出格式
- TIFF格式：使用 `'GTiff'` 导出格式
- 自动设置无效值：`-999`

## 十、珠江流域应用特点

### 10.1 珠江流域水体特征

**地理特征**:
- 珠江流域是中国南方最大的流域之一
- 包括西江、北江、东江三大支流
- 流经多个省份，最终汇入南海

**水体特点**:
- 受季风气候影响，季节性变化明显
- 汛期（4-9月）径流量大，悬浮物浓度高
- 枯水期（10-3月）径流量小，水质相对稳定
- 河口区域受潮汐影响，水质变化复杂

### 10.2 富营养化评估注意事项

**季节性变化**:
- **汛期**: 悬浮物浓度高，TLI值可能偏高
- **枯水期**: 悬浮物浓度低，TLI值可能偏低
- **水华高发期**: 叶绿素a浓度高，TLI值显著升高

**空间变化**:
- **上游**: 悬浮物为主，TLI值受悬浮物影响大
- **中下游**: 叶绿素a和悬浮物共同影响
- **河口区域**: 受咸淡水混合影响，TLI值变化复杂

**数据解释建议**:
1. **时间对比**: 建议使用同一季节的数据进行对比
2. **空间对比**: 考虑不同河段的水体特征差异
3. **综合评估**: 结合实测数据验证计算结果
4. **趋势分析**: 多期数据对比，识别长期变化趋势

### 10.3 实际应用建议

1. **数据选择**
   - 选择云量少、质量好的影像
   - 优先选择同一季节的数据
   - 考虑水文条件（水位、流量）

2. **结果验证**
   - 结合实测水质数据验证
   - 对比不同时期的变化趋势
   - 识别异常值和异常区域

3. **结果应用**
   - 用于富营养化监测和预警
   - 用于水质评估和管理
   - 用于环境变化趋势分析
