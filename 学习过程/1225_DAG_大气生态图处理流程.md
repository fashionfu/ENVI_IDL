# GSF_AtmosphericEcology_Flow DAG任务调用说明

## 📋 概述

`GSF_AtmosphericEcology_Flow` 是一个ENVI Services Engine (ESE)的DAG（有向无环图）元任务，用于从原始影像到大气生态图的自动化处理流程。该流程包含以下步骤：

1. **辐射定标** (GSF_GF1_RadiometricCorrection) - 将DN值转换为辐射亮度
2. **大气校正** (GSF_GF1_FLAASH_AtmosphericCorrection) - 去除大气影响，获取地表反射率
3. **正射校正** (GSF_RPCOrthorectification) - 进行几何校正，消除地形和传感器姿态影响
4. **波段运算-城市热岛分析** (GSF_UrbanHeatIsland_LC8) - 计算城市热岛效应（适用于Landsat 8数据）
5. **波段运算-地表温度计算** (ENVILandsat8LSTTask) - 计算地表温度（LST）
6. **生成预览和下载** (GSF_GetFileURL) - 生成预览图、ZIP文件等

---

## 🔧 任务配置文件

**文件位置**: `Task/metatasks/GSF_AtmosphericEcology_Flow.task`

**任务类型**: DAG Metatask（元任务）

**服务类型**: JavaScript Service（注意：不是ENVI Service）

## 📡 API调用方式

### 1. 基本调用信息

**API端点**:
```
POST http://localhost:9191/ese/services/javascript/GSF_AtmosphericEcology_Flow/submitJob
```

**重要说明**:
- ✅ DAG任务使用 `javascript` 服务，不是 `ENVI` 服务
- ✅ 普通ENVI任务使用: `/ese/services/ENVI/{task}/submitJob`
- ✅ DAG任务使用: `/ese/services/javascript/{task}/submitJob`

### 2. 请求参数

**Content-Type**: `application/json`

**请求体格式** (JSON):

```json
{
  "input_file": "E:/data/Landsat8_xxx.tar.gz",
  "sensor_type": "Landsat8",
  "dem_file": "E:/dem/gmted2010.dat",
  "base_file": "",
  "mss_pixel_size": "30.0",
  "output_path": "E:/output/",
  "visibility": 40.0,
  "aerosol_model": "Urban"
}
```

**参数说明**:

| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| `input_file` | string | ✅ 是 | 输入文件路径（.tar.gz压缩包或影像文件，支持Landsat 8/9数据） |
| `sensor_type` | string | ✅ 是 | 传感器类型（如：Landsat8, Landsat9等） |
| `dem_file` | string | ❌ 否 | DEM文件路径（可选，默认使用GMTED2010） |
| `base_file` | string | ❌ 否 | 基准文件路径（可选） |
| `mss_pixel_size` | string | ❌ 否 | 多光谱像素大小（米，如"30.0"） |
| `output_path` | string | ❌ 否 | 输出文件路径（可选） |
| `visibility` | double | ❌ 否 | 能见度（公里），用于FLAASH大气校正，默认40.0 |
| `aerosol_model` | string | ❌ 否 | 气溶胶模型，可选：No Aerosol, Rural, Maritime, Urban, Tropospheric，默认"Urban" |

### 3. 响应格式

**成功响应**:

```json
{
  "jobId": "job_1234567890",
  "jobStatusURL": "ese/jobs/job_1234567890/status"
}
```

**响应字段**:
- `jobId`: 任务ID，用于后续查询任务状态
- `jobStatusURL`: 任务状态查询URL的相对路径

## 🔄 任务执行流程

### DAG任务内部流程

```
输入: 原始影像文件（Landsat 8/9）
    │
    ▼
[GSF_GF1_RadiometricCorrection]
    │ 辐射定标：DN值 → 辐射亮度
    │
    ▼
[GSF_GF1_FLAASH_AtmosphericCorrection]
    │ 大气校正：辐射亮度 → 地表反射率
    │
    ▼
[GSF_RPCOrthorectification]
    │ 正射校正：几何校正
    │
    ├─────────────────────────────────┐
    │                                   │
    ▼                                   ▼
[GSF_UrbanHeatIsland_LC8]      [ENVILandsat8LSTTask]
    │ 城市热岛分析                         │ 地表温度计算
    │                                   │
    └───────────────────────────────────┘
                    │
                    ▼
            [GSF_GetFileURL]
                    │
                    └─→ out_options {
                          PngFileURL: "预览图URL",
                          MapExtent: "地图范围",
                          ZipFileURL: "ZIP文件URL",
                          UrbanHeatIsland: "城市热岛结果",
                          LandSurfaceTemperature: "地表温度结果"
                        }
```

### 任务依赖关系

1. **GSF_GF1_RadiometricCorrection** (无依赖)
   - 输入: `input_file` (外部)
   - 输出: `OUTPUT_RASTER` (辐射定标后的影像)

2. **GSF_GF1_FLAASH_AtmosphericCorrection** (依赖: GSF_GF1_RadiometricCorrection)
   - 输入: `GSF_GF1_RadiometricCorrection.OUTPUT_RASTER` (内部)
   - 输入: `visibility`, `aerosol_model` (外部)
   - 输出: `OUTPUT_RASTER` (大气校正后的影像)

3. **GSF_RPCOrthorectification** (依赖: GSF_GF1_FLAASH_AtmosphericCorrection)
   - 输入: `GSF_GF1_FLAASH_AtmosphericCorrection.OUTPUT_RASTER` (内部)
   - 输入: `sensor_type`, `dem_file`, `base_file`, `mss_pixel_size` (外部)
   - 输出: `OUTPUT_RASTER` (正射校正后的影像)

4. **GSF_UrbanHeatIsland_LC8** (依赖: GSF_RPCOrthorectification)
   - 输入: `GSF_RPCOrthorectification.OUTPUT_RASTER` (内部)
   - 输出: `OUTPUT_RASTER` (城市热岛分析结果)

5. **ENVILandsat8LSTTask** (依赖: GSF_RPCOrthorectification)
   - 输入: `GSF_RPCOrthorectification.OUTPUT_RASTER` (内部)
   - 输出: `OUTPUT_RASTER` (地表温度结果)

6. **GSF_GetFileURL** (依赖: GSF_UrbanHeatIsland_LC8, ENVILandsat8LSTTask)
   - 输入: `GSF_UrbanHeatIsland_LC8.OUTPUT_RASTER` (内部)
   - 输入: `ENVILandsat8LSTTask.OUTPUT_RASTER` (内部)
   - 输出: `out_options` (外部)

## 💻 前端调用示例

### JavaScript/jQuery调用

```javascript
// 1. 构建任务参数
var params = {
    'input_file': 'E:/data/LC08_L1TP_123045_20230101_20230101_02_RT.tar.gz',
    'sensor_type': 'Landsat8',
    'dem_file': 'E:/dem/gmted2010.dat',
    'base_file': '',
    'mss_pixel_size': '30.0',
    'output_path': 'E:/output/',
    'visibility': 40.0,
    'aerosol_model': 'Urban'
};

// 2. 调用submitJob函数
function submitJob(task, params, callback, timestamp) {
    var taskUrl;
    if(task == 'GSF_AtmosphericEcology_Flow'){
        // DAG任务使用javascript服务
        taskUrl = "http://localhost:9191/ese/services/javascript/" + task + "/submitJob";
    } else {
        // 普通任务使用ENVI服务
        taskUrl = "http://localhost:9191/ese/services/ENVI/" + task + "/submitJob";
    }
    
    $.post(taskUrl, params, function (data) {
        // 处理响应
        console.log('Job ID:', data.jobId);
        console.log('Status URL:', data.jobStatusURL);
        
        // 开始轮询任务状态
        var statusURL = 'http://localhost:9191/' + data.jobStatusURL;
        poll(statusURL, callback, timestamp);
    });
}

// 3. 调用任务
var timestamp = new Date().getTime();
submitJob('GSF_AtmosphericEcology_Flow', params, function(success, data) {
    if (success) {
        console.log('任务完成！', data);
        // 处理结果
        var pngUrl = data.results[0].value.elements.PngFileURL.dehydratedForm;
        var mapExtent = data.results[0].value.elements.MapExtent.dehydratedForm;
        var zipUrl = data.results[0].value.elements.ZipFileURL.dehydratedForm;
        var uhiResult = data.results[0].value.elements.UrbanHeatIsland.dehydratedForm;
        var lstResult = data.results[0].value.elements.LandSurfaceTemperature.dehydratedForm;
    } else {
        console.error('任务失败！', data);
    }
}, timestamp);
```

## 📊 任务状态查询

### 查询任务状态

**API端点**:
```
GET http://localhost:9191/ese/jobs/{jobId}/status
```

**示例**:
```javascript
function poll(statusURL, callback, timestamp) {
    $.get(statusURL, function(data) {
        console.log('任务状态:', data.status);
        console.log('进度:', data.progress);
        
        if (data.status === 'COMPLETED') {
            // 任务完成
            callback(true, data);
        } else if (data.status === 'FAILED') {
            // 任务失败
            callback(false, data);
        } else {
            // 任务进行中，继续轮询
            setTimeout(function() {
                poll(statusURL, callback, timestamp);
            }, 2000); // 每2秒查询一次
        }
    });
}
```

**状态值**:
- `JobAccepted`: 任务已接受
- `JobRunning`: 任务运行中
- `COMPLETED`: 任务完成
- `FAILED`: 任务失败
- `CANCELLED`: 任务已取消

## ⚠️ 注意事项

### 1. 服务类型区别

- **DAG任务** (`GSF_AtmosphericEcology_Flow`): 使用 `javascript` 服务
  - URL: `/ese/services/javascript/GSF_AtmosphericEcology_Flow/submitJob`
  
- **普通ENVI任务**: 使用 `ENVI` 服务
  - URL: `/ese/services/ENVI/{task}/submitJob`

### 2. 数据要求

- **输入数据**: 支持Landsat 8/9 Level 1数据
- **必需波段**: 多光谱波段（B1-B7）和热红外波段（B10/B11）
- **数据格式**: 支持.tar.gz压缩包或解压后的影像文件

### 3. 参数设置建议

- **能见度**: 根据实际天气条件设置，城市区域一般30-50公里
- **气溶胶模型**: 城市区域建议选择"Urban"，农村区域选择"Rural"
- **像素大小**: Landsat 8多光谱为30米，热红外为100米（重采样到30米）

### 4. 任务执行时间

- DAG任务包含多个子任务，执行时间较长
- 建议设置合理的轮询间隔（2-5秒）
- 大文件处理可能需要数分钟到数小时

### 5. 错误处理

- 检查任务状态返回的错误信息
- 查看ESE服务器日志获取详细错误
- 确保所有依赖任务都已正确配置
- 确保Landsat数据包含热红外波段

## 🔍 调试技巧

### 1. 检查任务配置

确保 `GSF_AtmosphericEcology_Flow.task` 文件在正确位置：
```
Task/metatasks/GSF_AtmosphericEcology_Flow.task
```

### 2. 验证子任务

确保所有子任务都已正确注册：
- `GSF_GF1_RadiometricCorrection`
- `GSF_GF1_FLAASH_AtmosphericCorrection`
- `GSF_RPCOrthorectification`
- `GSF_UrbanHeatIsland_LC8`
- `ENVILandsat8LSTTask`
- `GSF_GetFileURL`

### 3. 查看ESE日志

ESE服务器日志通常位于：
- Windows: `C:\Program Files\Harris\ENVI Services Engine\logs\`
- Linux: `/opt/harris/envi-services-engine/logs/`

### 4. 测试单个任务

在调用DAG任务之前，可以先测试单个子任务是否正常工作。

### 5. 数据验证

- 确保Landsat数据包含MTL元数据文件
- 验证热红外波段数据可用
- 检查数据覆盖区域是否包含城市区域
