## 一、代码概述

### 1.1 功能描述

`GSF_GF1_VegetationIndices` 是一个用于计算高分一号（GF-1）PMS数据多种植被指数的ENVI Task模块。该模块实现了六种常用的植被指数：
- **NDVI（归一化植被指数）**：最常用的植被指数，反映植被覆盖度和生长状况
- **EVI（增强植被指数）**：减少土壤和大气影响，对高生物量区域更敏感
- **GNDVI（绿色归一化植被指数）**：对叶绿素含量敏感，适用于作物监测
- **LAI（叶面积指数）**：基于NDVI的经验公式，反映单位地表面积上的叶片总面积
- **SAVI（土壤调整植被指数）**：考虑土壤背景影响，适用于稀疏植被区域
- **TDVI（变换植被指数）**：增强植被信号，减少背景噪声

### 2.4 波段运算实现（核心算法）

**位置**: 第198-445行

**关键改进**: 完全按照 `GSF_GF1_ChlorophyllA.pro` 的波段运算方式实现

#### 2.4.1 波段编号说明

**GF1-PMS波段配置**:
- B1(蓝, 索引0) → PixelwiseBandMathRaster中的 `b1`
- B2(绿, 索引1) → PixelwiseBandMathRaster中的 `b2`
- B3(红, 索引2) → PixelwiseBandMathRaster中的 `b3`
- B4(近红外, 索引3) → PixelwiseBandMathRaster中的 `b4`

**注意**: `PixelwiseBandMathRaster` 使用 `b1, b2, b3...` 表示波段，索引从1开始（不是0）。

#### 2.4.2 算法1：NDVI（归一化植被指数）

**位置**: 第213-244行

**公式**:
```
NDVI = (NIR - Red) / (NIR + Red)
```
其中：
- `b3` = 红波段(B3)
- `b4` = 近红外波段(B4)

**实现方式**:
```idl
expression = '(FLOAT(b4) - FLOAT(b3)) / (FLOAT(b4) + FLOAT(b3))'

vegeTask = ENVITask('PixelwiseBandMathRaster')
vegeTask.INPUT_RASTER = Raster
vegeTask.EXPRESSION = expression
vegeTask.Execute
VegeIndexRaster = vegeTask.OUTPUT_RASTER
```

**关键点**:
- 使用 `ENVITask('PixelwiseBandMathRaster')` 而不是 `ENVIPixelwiseBandMathRaster` 函数
- 直接使用整个 `Raster` 对象，不需要先提取子波段
- 使用 `FLOAT()` 确保浮点运算精度

#### 2.4.3 算法2：EVI（增强植被指数）

**位置**: 第246-277行

**公式**:
```
EVI = 2.5 × (NIR - Red) / (NIR + 6×Red - 7.5×Blue + 1)
```

**实现方式**:
```idl
expression = '2.5 * (FLOAT(b4) - FLOAT(b3)) / (FLOAT(b4) + 6.0 * FLOAT(b3) - 7.5 * FLOAT(b1) + 1.0)'
```

**关键点**:
- 需要三个波段：蓝、红、近红外
- 通过调整系数减少土壤和大气影响

#### 2.4.4 算法3：GNDVI（绿色归一化植被指数）

**位置**: 第279-310行

**公式**:
```
GNDVI = (NIR - Green) / (NIR + Green)
```

**实现方式**:
```idl
expression = '(FLOAT(b4) - FLOAT(b2)) / (FLOAT(b4) + FLOAT(b2))'
```

**关键点**:
- 使用绿波段代替红波段
- 对叶绿素含量更敏感

#### 2.4.5 算法4：LAI（叶面积指数）

**位置**: 第312-372行

**公式**:
```
LAI = -ln((0.69 - NDVI) / 0.59) / 0.91  (当 0.1 ≤ NDVI ≤ 0.69)
LAI = 0  (当 NDVI < 0.1)
LAI = 6  (当 NDVI > 0.69，饱和值)
```

**实现方式**:
```idl
; 先计算NDVI
ndvi_expr = '(FLOAT(b4) - FLOAT(b3)) / (FLOAT(b4) + FLOAT(b3))'
ndviTask = ENVITask('PixelwiseBandMathRaster')
ndviTask.INPUT_RASTER = Raster
ndviTask.EXPRESSION = ndvi_expr
ndviTask.Execute
NDVIRaster = ndviTask.OUTPUT_RASTER

; 基于NDVI计算LAI
lai_expr = '(FLOAT(b1) GE 0.1 AND FLOAT(b1) LE 0.69) * (-ALOG((0.69 - FLOAT(b1)) / 0.59) / 0.91) + (FLOAT(b1) LT 0.1) * 0.0 + (FLOAT(b1) GT 0.69) * 6.0'
laiTask = ENVITask('PixelwiseBandMathRaster')
laiTask.INPUT_RASTER = NDVIRaster
laiTask.EXPRESSION = lai_expr
laiTask.Execute
VegeIndexRaster = laiTask.OUTPUT_RASTER
```

**关键点**:
- 需要两步计算：先计算NDVI，再基于NDVI计算LAI
- 使用条件表达式处理不同NDVI范围
- 这是唯一需要两步计算的植被指数

#### 2.4.6 算法5：SAVI（土壤调整植被指数）

**位置**: 第374-405行

**公式**:
```

```

**实现方式**:


**关键点**:
- 在NDVI基础上添加土壤调整因子（0.5）
- 适用于稀疏植被区域

#### 2.4.7 算法6：TDVI（变换植被指数）

**位置**: 第407-438行

```

```

## 四、算法详细说明

### 4.1 NDVI（归一化植被指数）

**理论基础**: Rouse等（1974）提出的归一化植被指数

**公式**:
```
NDVI = (NIR - Red) / (NIR + Red)
```

**适用场景**:
- 植被覆盖度监测
- 植被生长状况评估
- 大范围植被变化监测

**优点**:
- 计算简单快速
- 对大多数植被类型适用
- 值域范围：-1 到 1，易于解释

**局限性**:
- 在稀疏植被区域受土壤背景影响
- 在高生物量区域容易饱和

### 4.2 EVI（增强植被指数）

**理论基础**: Huete等（2002）提出的增强植被指数

**公式**:
```
EVI = 2.5 × (NIR - Red) / (NIR + 6×Red - 7.5×Blue + 1)
```

**适用场景**:
- 高生物量区域监测
- 需要减少大气和土壤影响的场景
- 作物长势监测

**优点**:
- 减少土壤背景影响
- 减少大气影响
- 对高生物量区域更敏感

**局限性**:
- 需要蓝波段，对数据质量要求较高
- 计算相对复杂

### 4.3 GNDVI（绿色归一化植被指数）

**理论基础**: Gitelson等（1996）提出的绿色归一化植被指数

**公式**:
```
GNDVI = (NIR - Green) / (NIR + Green)
```

**适用场景**:
- 作物叶绿素含量监测
- 作物营养状况评估
- 精准农业应用

**优点**:
- 对叶绿素含量敏感
- 适用于作物监测
- 计算简单

**局限性**:
- 在非植被区域效果较差
- 对数据质量要求较高

### 4.4 LAI（叶面积指数）

**理论基础**: 基于NDVI的经验公式（Chen等，2002）

**公式**:
```
LAI = -ln((0.69 - NDVI) / 0.59) / 0.91  (当 0.1 ≤ NDVI ≤ 0.69)
LAI = 0  (当 NDVI < 0.1)
LAI = 6  (当 NDVI > 0.69，饱和值)
```

**适用场景**:
- 植被生产力评估
- 生态系统碳循环研究
- 农业产量估算

**优点**:
- 反映植被结构参数
- 与植被生物量相关
- 适用于生态系统研究

**局限性**:
- 基于经验公式，精度有限
- 需要先计算NDVI，计算步骤较多
- 对于特定区域可能需要调整参数

### 4.5 SAVI（土壤调整植被指数）

**理论基础**: Huete（1988）提出的土壤调整植被指数

**公式**:
```
SAVI = 1.5 × (NIR - Red) / (NIR + Red + 0.5)
```

**适用场景**:
- 稀疏植被区域监测
- 干旱半干旱地区植被监测
- 土壤背景影响较大的区域

**优点**:
- 考虑土壤背景影响
- 适用于稀疏植被
- 计算简单

**局限性**:
- 土壤调整因子（0.5）是固定值，可能不适用于所有情况
- 在密集植被区域效果与NDVI相似

### 4.6 TDVI（变换植被指数）

**理论基础**: 基于NDVI的变换，增强植被信号

**公式**:
```
TDVI = sqrt((NIR - Red) / (NIR + Red) + 0.5)
```

**适用场景**:
- 低植被覆盖区域监测
- 需要增强植被信号的场景
- 背景噪声较大的区域

**优点**:
- 增强植被信号
- 减少背景噪声
- 适用于低植被覆盖区域

**局限性**:
- 计算相对复杂
- 应用相对较少，研究不够深入

## 八、技术细节

### 8.1 ENVI Task集成

**任务定义文件** (`GSF_GF1_VegetationIndices.task`):
- 使用 `ENVITaskFromProcedure` 基类
- 参数类型：`ENVIURI`（输入文件）、`string`（植被指数类型）、`string`（输出格式）
- 支持必需参数和可选参数
- 提供默认值和选择列表
- 支持"ALL"选项（在UI中实现批处理）

### 8.2 波段运算表达式

**表达式语法**:
- 使用 `b1, b2, b3...` 表示波段（从1开始）
- 使用 `FLOAT()` 确保浮点运算
- 支持数学运算符：`+`, `-`, `*`, `/`, `^`, `SQRT`, `ALOG`
- 支持条件表达式：`GT`, `LT`, `GE`, `LE`, `EQ`, `AND`, `OR`

**示例表达式**:
```idl
; NDVI
'(FLOAT(b4) - FLOAT(b3)) / (FLOAT(b4) + FLOAT(b3))'

; EVI
'2.5 * (FLOAT(b4) - FLOAT(b3)) / (FLOAT(b4) + 6.0 * FLOAT(b3) - 7.5 * FLOAT(b1) + 1.0)'

; LAI（带条件判断）
'(FLOAT(b1) GE 0.1 AND FLOAT(b1) LE 0.69) * (-ALOG((0.69 - FLOAT(b1)) / 0.59) / 0.91) + (FLOAT(b1) LT 0.1) * 0.0 + (FLOAT(b1) GT 0.69) * 6.0'
```

### 8.3 文件I/O处理

**输入文件**:
- 支持ENVI格式（`.dat/.hdr`）
- 支持TIFF格式
- 自动检测文件格式
- 支持ENVIURI对象

**输出文件**:
- ENVI格式：使用 `'ENVI'` 导出格式
- TIFF格式：使用 `'GTiff'` 导出格式
- 自动设置无效值：`-999`
- 文件名包含植被指数类型（如 `_NDVI.dat`）

### 8.4 UI面板实现

**UI程序** (`GSF_GF1_VegetationIndices_ui.pro`):
- 使用 `e.UI.SelectTaskParameters` 显示参数设置面板
- 支持"ALL"选项的批处理
- 自动循环处理所有植被指数
- 每个指数计算完成后显示结果
- 设置 `GET_OUT_OPTIONS = 0` 避免SPAWN错误
