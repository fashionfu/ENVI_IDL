## 概述

### 功能描述

本模块实现了高分一号（GF1）卫星影像的RPC（Rational Polynomial Coefficients，有理多项式系数）正射校正功能。支持GF1-PMS和GF1-WFV两种传感器类型，能够自动识别输入文件格式，并生成高精度的正射校正影像。

### 主要特性

- ✅ **多格式支持**：支持.tar.gz压缩包、.xml原始数据、.dat/.hdr ENVI格式
- ✅ **自动参数设置**：根据传感器类型自动设置像素大小（GF1-PMS MSS: 7.3m）
- ✅ **高精度匹配**：与官方GUI结果高度一致（平均差异<3 DN，相对差异<1.1%）
- ✅ **批量处理**：支持UI界面批量处理多个文件
- ✅ **错误处理**：完善的错误处理和调试信息输出

## 关键技术实现

### 1. 像素大小智能确定算法

**问题**：不同坐标系的PIXEL_SIZE单位不同
- 投影坐标系（PROJCS）：单位是米
- 地理坐标系（GEOGCS）：单位是度

**解决方案**：

```idl
; 检查坐标系类型
coord_sys_str = Raster.SPATIALREF.COORD_SYS_STR
coord_type = STRMID(coord_sys_str, 0, 6)
is_projected = STRMATCH(coord_type, 'PROJCS', /FOLD_CASE)

; 只有投影坐标系才使用PIXEL_SIZE
IF is_projected THEN BEGIN
  temp_pixel_size = Raster.SPATIALREF.PIXEL_SIZE
  ; 检查合理性（0.1米到1000米之间）
  IF (temp_avg GT 0.1) AND (temp_avg LT 1000.0) THEN BEGIN
    actual_pixel_size = temp_pixel_size
  ENDIF
ENDIF ELSE BEGIN
  ; 地理坐标系使用默认值
  mss_pixel_size = 7.3  ; GF1-PMS MSS默认值
ENDELSE
```

**效果**：
- ✅ 避免使用地理坐标系的度单位作为像素大小（会导致极小的像素值，如6.9e-05度）
- ✅ 自动使用传感器特定的默认值（GF1-PMS MSS: 7.3m）

### 2. .dat文件RPC信息读取

**问题**：输入.dat文件时，RPC信息存储在对应的.hdr文件中

**解决方案**：

```idl
IF input_file_lower.EndsWith('.dat') THEN BEGIN
  dat_pos = STRPOS(input_file_lower, '.dat', /reverse_search)
  hdr_file = STRMID(input_file, 0, dat_pos) + '.hdr'
  IF FILE_TEST(hdr_file) THEN BEGIN
    input_file_to_open = hdr_file  ; 使用.hdr文件打开
  ENDIF
ENDIF
Raster = e.OpenRaster(input_file_to_open)
```

**效果**：
- ✅ 自动检测.dat文件并查找对应的.hdr文件
- ✅ 确保RPC信息正确加载

### 3. OUTPUT_RASTER标量验证

**问题**：ENVI Task系统要求OUTPUT_RASTER必须是标量ENVIRaster对象

**解决方案**：

```idl
; 多次验证和重新打开
IF N_ELEMENTS(OUTPUT_RASTER) GT 1 THEN BEGIN
  OUTPUT_RASTER = OUTPUT_RASTER[0]  ; 取第一个元素
ENDIF

IF ~ISA(OUTPUT_RASTER) OR ~OBJ_VALID(OUTPUT_RASTER) THEN BEGIN
  ; 重新从文件打开
  OUTPUT_RASTER = e.OpenRaster(output_file)
ENDIF
```

**效果**：
- ✅ 确保OUTPUT_RASTER始终是标量对象
- ✅ 避免"Value must be a scalar ENVIRASTER"错误

### 4. SPAWN错误容错处理

**问题**：GSF_GetFileURL可能因系统资源不足导致SPAWN错误

**解决方案**：

```idl
CATCH, spawn_error
IF (spawn_error EQ 0) THEN BEGIN
  GSF_GetFileURL, OUTPUT_RASTER, out_options
  CATCH, /CANCEL
ENDIF ELSE BEGIN
  CATCH, /CANCEL
  PRINT, 'DEBUG: WARNING: Preview generation failed, but main result is OK'
  ; 重新打开OUTPUT_RASTER以确保有效性
  OUTPUT_RASTER = e.OpenRaster(output_file)
ENDELSE
```

**效果**：
- ✅ 预览图生成失败不影响主正射校正结果
- ✅ 主处理流程继续执行

   - 更小的像素大小会增加处理时间和文件大小

3. **重采样方法**：
   - Bilinear：平衡精度和速度（推荐）
   - Nearest Neighbor：最快，但精度较低
   - Cubic Convolution：最精确，但最慢

### 性能优化建议

1. **DEM文件选择**
   - 默认GMTED2010（30米）：平衡精度和速度
   - 高精度DEM（如10米）：提高精度，但增加处理时间
   - 低精度DEM（如90米）：加快处理，但精度降低

2. **像素大小设置**
   - 使用默认值（7.3m for MSS）：最佳性能
   - 更小像素（如3.65m）：提高分辨率，但增加处理时间和文件大小
   - 更大像素（如14.6m）：加快处理，但降低分辨率

3. **重采样方法选择**
   - Bilinear（推荐）：平衡精度和速度
   - Nearest Neighbor：最快，适合快速预览
   - Cubic Convolution：最精确，适合最终产品

### 常见问题解答

#### Q1: 为什么像素大小设置为7.3米而不是8.0米？

**A**: 7.3米是官方ENVI GUI的默认输出像素大小。通过对比测试发现，使用7.3米可以获得与官方结果完全一致的输出尺寸和像素大小，确保结果的可比性。

#### Q2: 处理速度慢怎么办？

**A**: 
- 检查DEM文件大小，使用较低分辨率的DEM
- 使用Nearest Neighbor重采样方法
- 增大输出像素大小（降低分辨率）
- 确保有足够的磁盘空间和内存

#### Q3: 出现"SPAWN error"怎么办？

**A**: SPAWN错误通常发生在预览图生成阶段，不影响主正射校正结果。可以：
- 忽略该警告，主结果已成功生成
- 检查系统资源（内存、磁盘空间）
- 如果不需要预览图，可以设置`get_out_options=0`

#### Q4: 如何验证结果精度？

**A**: 使用`GSF_Compare_RPC_Results.pro`工具与官方结果对比：
- 检查尺寸、像素大小、坐标系是否匹配
- 查看统计信息（Mean、StdDev）是否一致
- 分析像素值差异（平均差异应<5 DN）
