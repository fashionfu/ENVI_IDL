## 1. 概述

### 1.1 文档目的

本文档详细描述高分一号（GF1）PMS 影像无缝镶嵌的技术原理、处理流程和代码实现逻辑，为开发人员和用户提供完整的技术参考。

### 1.2 适用数据

| 卫星 | 传感器 | 波段数 | 支持状态 |
|:----:|:------:|:------:|:--------:|
| GF-1 | PMS1/PMS2 | 4 | 已验证 |
| GF-2 | PMS1/PMS2 | 4 | 支持（已测试） |

**注意**: 虽然任务名为 `GSF_GF1_SeamlessMosaic`，但实际代码不限制卫星类型，可处理任何具有标准空间参考的遥感影像。

### 1.3 技术依赖

- ENVI 5.x / 6.x
- IDL 8.x / 9.x
- 高分卫星 L1A 级产品（建议先进行正射校正）
- 多景具有重叠区域的影像

### 1.4 功能特点

- **多景影像拼接**: 将多景具有重叠区域的影像拼接成一张大范围无缝影像图
- **自动拼接线生成**: 支持基于几何的拼接线自动生成
- **羽化处理**: 在拼接线附近进行平滑过渡，消除接缝
- **色彩匹配**: 支持直方图匹配，统一多景影像的色彩风格
- **多种重叠区处理**: 支持 Top/Min/Max/Mean 四种重叠区取值方法
- **多种重采样方法**: 支持最近邻、双线性、三次卷积三种重采样方法

## 2. 无缝镶嵌原理

### 2.1 物理背景

遥感影像镶嵌是将多景具有重叠区域的影像拼接成一张大范围无缝影像图的过程。无缝镶嵌的核心在于：

1. **空间配准**: 确保多景影像在统一的空间参考系统下对齐
2. **重叠区处理**: 在重叠区域选择合适的像素值或进行融合
3. **接缝消除**: 通过拼接线生成、羽化等技术消除可见接缝
4. **色彩统一**: 通过色彩匹配技术统一多景影像的色彩风格

### 2.2 核心算法

#### 2.2.1 ENVIMosaicRaster 算法

本任务基于 ENVI 的 `ENVIMosaicRaster` 类实现，该类提供了完整的镶嵌功能：

```idl
mosaicRaster = ENVIMosaicRaster(              $
  scenes,                                     $
  resampling = resampling,                    $
  seamline_method = seamline_method,         $
  color_matching_method = color_matching_method, $
  feathering_method = feathering_method)
```

#### 2.2.2 拼接线生成方法

| 方法 | 说明 | 适用场景 |
|:-----|:-----|:---------|
| `geometry` | 基于几何形状的拼接线生成 | 自动生成，适用于大多数场景 |
| `none` | 不生成拼接线 | 简单拼接，快速处理 |

#### 2.2.3 羽化方法

| 方法 | 说明 | 效果 |
|:-----|:-----|:-----|
| `seamline` | 沿拼接线进行羽化 | 在拼接线附近平滑过渡 |
| `none` | 不进行羽化 | 直接拼接，可能有接缝 |

#### 2.2.4 色彩匹配方法

| 方法 | 说明 | 效果 |
|:-----|:-----|:-----|
| `histogram matching` | 直方图匹配 | 统一多景影像的色彩分布 |
| `none` | 不进行色彩匹配 | 保持原始色彩 |

#### 2.2.5 重叠区取值方法

| 方法 | 说明 | 公式 |
|:-----|:-----|:-----|
| `Top` | 最上值（默认） | 使用最上层影像的像素值 |
| `Min` | 最小值 | `min(pixel_values)` |
| `Max` | 最大值 | `max(pixel_values)` |
| `Mean` | 平均值 | `mean(pixel_values)` |

**注意**: `overlay_method` 参数在 `ENVIMosaicRaster` 中未直接使用，仅用于记录和后续扩展。

#### 2.2.6 重采样方法

| 方法 | 说明 | 特点 |
|:-----|:-----|:-----|
| `Nearest Neighbor` | 最近邻（默认） | 速度快，保持原始值 |
| `Bilinear` | 双线性插值 | 平滑过渡，适合连续数据 |
| `Cubic Convolution` | 三次卷积 | 最平滑，但计算量大 |

#### 3.2.1 文件搜索策略

```idl
; 根据输入格式确定搜索模式
CASE STRUPCASE(input_format) OF
  'ENVI': file2search = '*.hdr'
  'TIFF': file2search = '*.tif'
  ELSE: file2search = '*.hdr'
ENDCASE

; 搜索文件
input_files = file_search(input_path, file2search, count=count, /test_regular)
```

#### 3.2.2 拼接线与羽化设置

```idl
; 根据 generate_seamline 参数设置
CASE STRUPCASE(generate_seamline) OF
  'YES': BEGIN
    seamline_method = 'geometry'          ; 自动生成拼接线
    feathering_method = 'seamline'        ; 沿拼接线羽化
    color_matching_method = 'histogram matching'  ; 直方图匹配
  END
  ELSE: BEGIN
    seamline_method = 'none'              ; 不生成拼接线
    feathering_method = 'none'            ; 不羽化
    color_matching_method = 'none'         ; 不进行色彩匹配
  END
ENDCASE
```

#### 3.2.3 输出文件名生成

```idl
; 如果未指定 output_file，使用时间戳生成
IF rootName EQ '' THEN BEGIN
  rootName = GET_TIME_STRING(root='GF1_Mosaic_')
ENDIF

; 根据输出格式添加扩展名
CASE STRUPCASE(output_format) OF
  'ENVI': output_file = output_path + rootName + '.dat'
  'TIFF': output_file = output_path + rootName + '.tif'
  ELSE: output_file = output_path + rootName + '.dat'
ENDCASE
```

## 4. 代码实现细节

### 4.1 文件搜索模块

```idl
;═══════════════════════════════════════════════════════════════
; 文件搜索与验证
;═══════════════════════════════════════════════════════════════

; 根据输入格式确定搜索文件类型
CASE STRUPCASE(input_format) OF
  'ENVI': file2search = '*.hdr'
  'TIFF': file2search = '*.tif'
  ELSE: file2search = '*.hdr'
ENDCASE

; 搜索 input_path 目录下的文件
input_files = file_search(input_path, file2search, count=count, /test_regular)

; 验证文件数量
IF count EQ 0 THEN BEGIN
  e.ReportError, 'ERROR: No input files found in the specified directory: ' + input_path
  RETURN
ENDIF
```

### 4.2 影像打开模块

```idl
;═══════════════════════════════════════════════════════════════
; 打开所有输入影像
;═══════════════════════════════════════════════════════════════

scenes = !NULL
file_index = 0
FOREACH file, input_files DO BEGIN
  raster = e.OpenRaster(file)
  IF OBJ_VALID(raster) THEN BEGIN
    ; 获取文件尺寸信息（用于调试）
    ns = raster.NCOLUMNS
    nl = raster.NROWS
    nb = raster.NBANDS
    scenes = [scenes, raster]
    file_index = file_index + 1
  ENDIF ELSE BEGIN
    PRINT, 'WARNING: 文件打开失败，栅格对象无效'
  ENDELSE
ENDFOREACH
```

### 4.3 镶嵌处理模块

```idl

  ; 获取镶嵌栅格尺寸
```

### 4.5 错误处理模块

```idl
;═══════════════════════════════════════════════════════════════
; 通用错误处理
;═══════════════════════════════════════════════════════════════

CATCH, err
IF (err NE 0) THEN BEGIN
  CATCH, /CANCEL
  error_msg = !ERROR_STATE.MSG
  error_code = !ERROR_STATE.CODE
  
  ; 输出详细错误信息
  detailed_msg = 'ERROR: ' + error_msg + STRING(13B) + STRING(13B)
  IF KEYWORD_SET(input_path) THEN $
    detailed_msg = detailed_msg + 'Input Path: ' + input_path + STRING(13B)
  IF KEYWORD_SET(output_file) THEN $
    detailed_msg = detailed_msg + 'Output File: ' + output_file + STRING(13B)
  detailed_msg = detailed_msg + 'Please check the input parameters and try again.'
  
  e.ReportError, detailed_msg
  RETURN
ENDIF
```

## 5. 输入输出规范

### 5.1 输入文件要求

#### 5.1.1 必需条件

| 项目 | 要求 | 说明 |
|:-----|:-----|:-----|
| **文件数量** | ≥ 2 个 | 至少需要 2 景影像才能进行镶嵌 |
| **空间参考** | 必须具有 | 影像应具有标准空间参考系统 |
| **重叠区域** | 建议有 | 有重叠区域可获得更好的拼接效果 |
| **数据格式** | ENVI 或 TIFF | 支持两种格式，通过 input_format 指定 |

#### 5.1.2 输入目录结构

```
输入目录/
├── image1.hdr (或 image1.tif)
├── image1.dat (ENVI格式需要)
├── image2.hdr (或 image2.tif)
├── image2.dat
├── image3.hdr (或 image3.tif)
└── image3.dat
```

**注意**: 
- ENVI 格式需要 `.hdr` 和 `.dat` 文件对
- TIFF 格式只需要 `.tif` 文件
- 文件应具有相同的波段数和数据类型

### 5.2 输出文件规范

#### 5.2.1 ENVI 格式

| 文件 | 说明 |
|:-----|:-----|
| `*_Mosaic_*.dat` | 二进制数据文件，数据类型与输入相同 |
| `*_Mosaic_*.hdr` | ENVI 头文件，包含元数据和空间参考信息 |

#### 5.2.2 TIFF 格式

| 文件 | 说明 |
|:-----|:-----|
| `*_Mosaic_*.tif` | GeoTIFF 格式，包含空间参考信息 |

#### 5.2.3 输出文件命名规则

- **自动命名**: 如果未指定 `output_file`，使用时间戳生成文件名
- **命名格式**: `GF1_Mosaic_YYYYMMDD_HHMMSS.dat`（或 `.tif`）
- **示例**: `GF1_Mosaic_20241229_094739.dat`

### 5.3 参数说明

#### 5.3.1 输入参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|:-------|:-----|:----:|:------:|:-----|
| `input_path` | string | 是 | - | 输入目录路径 |
| `input_format` | string | 否 | ENVI | 输入文件格式（ENVI/TIFF） |
| `data_ignore_value` | double | 否 | 0.0 | 数据忽略值 |
| `generate_seamline` | string | 否 | No | 是否自动生成拼接线（Yes/No） |
| `overlay_method` | string | 否 | Top | 重叠区取值方法（Top/Min/Max/Mean） |
| `resampling` | string | 否 | Nearest Neighbor | 重采样方法 |
| `output_format` | string | 否 | ENVI | 输出文件格式（ENVI/TIFF） |
| `output_path` | string | 否 | 临时目录 | 输出目录路径 |
| `get_out_options` | bool | 否 | false | 是否获取输出信息 |

#### 5.3.2 输出参数

| 参数名 | 类型 | 说明 |
|:-------|:-----|:-----|
| `OUTPUT_RASTER` | ENVIRaster | 镶嵌后的栅格对象 |
| `output_file` | string | 输出文件路径 |
| `out_options` | hash | 输出信息（预览图、压缩包等） |

## 6. 验证与精度分析

### 6.1 验证方法

#### 6.1.1 功能验证

1. **基本拼接**: 验证多景影像能否成功拼接
2. **空间参考**: 验证输出影像的空间参考是否正确
3. **数据完整性**: 验证输出数据是否完整，无缺失
4. **重叠区处理**: 验证重叠区域的像素值是否合理

#### 6.1.2 质量验证

1. **接缝检查**: 目视检查拼接结果是否有明显接缝
2. **色彩一致性**: 检查多景影像的色彩是否统一
3. **几何精度**: 检查拼接后的几何精度是否满足要求

### 6.2 测试案例

#### 6.2.1 测试数据

- **数据源**: GF2-PMS1 多光谱影像（5 景）
- **影像尺寸**: 约 27000 × 24000 像素
- **波段数**: 4 个波段
- **重叠区域**: 有重叠
- **空间参考**: 具有标准空间参考

#### 6.2.2 处理结果

| 项目 | 结果 |
|:-----|:-----|
| **输入文件数** | 5 个 |
| **镶嵌耗时** | 约 0.02 秒 |
| **导出耗时** | 约 311 秒（32GB 文件） |
| **输出文件大小** | 32.5 GB |
| **输出尺寸** | 43682 × 97659 × 4 |
| **处理状态** | 成功 |

### 6.3 性能分析

#### 6.3.1 处理时间

| 步骤 | 耗时 | 说明 |
|:-----|:----:|:-----|
| 文件搜索 | < 1 秒 | 取决于文件数量 |
| 打开影像 | ~ 4 秒 | 5 个文件，每个约 0.8 秒 |
| 创建镶嵌 | ~ 0.02 秒 | 非常快 |
| 导出结果 | ~ 311 秒 | 取决于输出文件大小 |
| **总计** | **~ 315 秒** | 约 5 分钟 |

#### 6.3.2 内存使用

- **输入数据**: 5 景影像，每景约 2.6 GB（27000 × 24000 × 4 × 2 字节）
- **镶嵌处理**: ENVI 内部优化，内存使用取决于重叠区域大小
- **输出数据**: 32.5 GB（43682 × 97659 × 4 × 2 字节）

### 6.4 已知限制

1. **内存限制**: 处理超大影像时可能受内存限制
2. **SPAWN 错误**: `GSF_GetFileURL` 可能因系统环境问题失败（不影响主流程）
3. **处理时间**: 导出大文件需要较长时间（数十GB文件可能需要数分钟）

```idl
  color_matching_method = color_matching_method, $  ; 色彩匹配方法
  feathering_method = feathering_method)      ; 羽化方法
```

**参数说明**:
- `scenes`: 输入栅格数组，至少需要 2 个栅格对象
- `resampling`: 重采样方法（'Nearest Neighbor' / 'Bilinear' / 'Cubic Convolution'）
- `seamline_method`: 拼接线方法（'geometry' / 'none'）
- `color_matching_method`: 色彩匹配方法（'histogram matching' / 'none'）
- `feathering_method`: 羽化方法（'seamline' / 'none'）

#### 7.2.2 Export 方法

```idl
mosaicRaster.Export, output_file, output_format
```

**支持的格式**:
- `'ENVI'`: ENVI 标准格式（.dat + .hdr）
- `'TIFF'`: GeoTIFF 格式（.tif）

### 8.2 开发过程中遇到的问题

#### 8.2.1 编译错误：IF/ELSE/ENDELSE 结构

**错误信息**:
```
% Type of end does not match statement (ENDELSE expected).
```

**原因**: IDL 中 `IF ... THEN BEGIN ... ENDIF ELSE BEGIN ... ENDELSE` 的语法要求严格。

**修复**: 确保所有 `IF ... ELSE BEGIN` 结构都以 `ENDELSE` 结束。

```idl
; 正确写法
IF condition THEN BEGIN
  ...
ENDIF ELSE BEGIN
  ...
ENDELSE
```

#### 8.2.2 编译错误：CATCH 块语法

**错误信息**:
```
% Attempt to call undefined procedure: 'ENDCATCH'.
```

**原因**: IDL 中 CATCH 块应使用 `END` 而不是 `ENDCATCH`。

**修复**: 将 `ENDCATCH` 替换为 `END`。

```idl
; 正确写法
BEGIN
  ...
END
CATCH
  ...
END
```

#### 8.2.3 运行时错误：STRLEN 未定义变量

**错误信息**:
```
% STRLEN: Variable is undefined: OUTPUT_FILE.
```

**原因**: 在 `output_file` 未定义时调用 `STRLEN(output_file)`。

**修复**: 使用嵌套 IF 结构，先检查 `KEYWORD_SET`，再检查类型和长度。

```idl
; 修复后
IF KEYWORD_SET(output_file) THEN BEGIN
  IF (SIZE(output_file, /TNAME) EQ 'STRING') THEN BEGIN
    IF (STRLEN(output_file) GT 0) THEN BEGIN
      ; 使用 output_file
    ENDIF
  ENDIF
ENDIF
```

#### 8.2.4 运行时错误：FLUSH 参数错误

**错误信息**:
```
% FLUSH: Incorrect number of arguments.
```

**原因**: IDL 中 `FLUSH` 需要单位号参数，或直接移除（PRINT 通常立即输出）。

**修复**: 移除所有 `FLUSH` 语句。

#### 8.2.5 运行时错误：FILE_INFO 语法错误

**错误信息**:
```
% Syntax error.
```

**原因**: `FILE_INFO(output_file).size` 语法不正确。

**修复**: 使用正确的语法。

```idl
; 修复后
fileInfo = FILE_INFO(output_file)
file_size = fileInfo[0].size
```

#### 8.2.6 运行时错误：SPAWN 错误

**错误信息**:
```
% SPAWN: Error executing spawn command.
```

**原因**: `GSF_GetFileURL` 调用外部命令失败（生成预览图或压缩包时）。

**修复**: 
1. 添加错误处理，使用 `CATCH` 捕获错误
2. 将 `get_out_options` 默认值改为 `false`，跳过预览图生成

```idl
; 修复后
IF get_out_options THEN BEGIN
  CATCH, geturl_err
  IF geturl_err EQ 0 THEN BEGIN
    GSF_GetFileURL, ...
    CATCH, /CANCEL
  ENDIF ELSE BEGIN
    CATCH, /CANCEL
    ; 设置基本的 out_options
    out_options = HASH('output_file', output_file)
  ENDELSE
ENDIF
```
