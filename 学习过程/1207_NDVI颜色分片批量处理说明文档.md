## 概述

本工具用于对 **Landsat L2 Surface Reflectance 数据** 和 **高分一号（GF1）多光谱数据** 进行 **NDVI（归一化植被指数）计算 + 颜色分片分类** 的批量处理。

设计目标：
- 同一套 UI 流程，兼容两种数据源（Landsat L2 / GF1）
- 自动识别波段并计算 NDVI
- 将 NDVI 值在 \[-1, 1] 范围内进行分级，可灵活指定分类数与颜色表
- 统一输出到指定目录，方便后续制图与分析

默认示例路径（可在 UI 中修改）：
- Landsat L2：`D:\FTPfiles\guangzhou\2024年\2024年第一季度\LC08_L2SP_129042_20161208_20200905_02_T1`
- GF1：`D:\FTPfiles\guangzhou\2024年\2024年第一季度\GF1原始像元值\GF1_PMS1_E113.3_N22.7_20240213_L1A13282365001_MSS.tif`
- 输出目录：`D:\FTPfiles\guangzhou\2024年\2024年第一季度\GF1处理`

## 支持的数据类型与波段要求

### Landsat L2 Surface Reflectance 数据

- 通过 `*_MTL.xml` 或 `*_MTL.txt` 打开数据包  
- 从 MTL 中选择 **Surface Reflectance** 数据集
- 波段配置假定为 Landsat 8/9 OLI 标准：
  - B1: Coastal / Aerosol
  - B2: Blue
  - B3: Green
  - **B4: Red（用于 NDVI）**
  - **B5: NIR（用于 NDVI）**
  - B6: SWIR1
  - B7: SWIR2

波段要求：
- 至少 **5 个波段**（至少包含 Red、NIR 两个波段）

### 高分一号（GF1）多光谱数据

- 输入为 TIF 格式多光谱影像
- 默认波段顺序假定为：
  - B1: Blue
  - B2: Green
  - **B3: Red**
  - **B4: NIR**

波段要求：
- 至少 **4 个波段**（Red 与 NIR 必须存在）

> 如果实际 GF1 产品的波段顺序不同，需要相应修改 `NDVIColorSliceBatchTask.pro` 中的波段索引映射。

## 处理流程总览

整体流程可以概括为：

1. **UI 层（`batch_ndvi_colorslice_UI.pro`）**
   - 选择数据类型（Landsat / GF1）
   - 打开输入数据（MTL 或 TIF）
   - 选择输出目录
   - 调用 Task UI 设置颜色分片参数
   - 调用 `NDVIColorSliceBatchTask` 执行批量处理

2. **任务层（`NDVIColorSliceBatchTask.pro`）**
   1. 遍历 `INPUT_RASTERS`
   2. 对每个栅格：
      - 检查 / 尝试补充波长信息
      - 计算 NDVI（SpectralIndex 或 手动 BandMath）
      - 采样统计 NDVI 值范围（诊断）
      - 将 NDVI 限制在 \[-1, 1]
      - 生成输出文件名并删除旧结果
      - 调用 `ColorSliceClassification` 进行颜色分片
      - 输出结果并添加到 Data Manager
      - 记录可能的错误信息
   3. 处理结束后，如有错误，弹出统一错误列表窗口。

## 核心算法与实现细节

### 1. 波长信息检查与补充（Landsat）

核心代码逻辑（简化描述）：

```idl
hasWavelength = 0
; 尝试读取 WAVELENGTH
wavelengths = raster.WAVELENGTH
IF wavelengths NE !NULL AND N_ELEMENTS(wavelengths) GT 0 THEN hasWavelength = 1

; 如果缺少波长，按 Landsat 8/9 标准波长补充
landSat8Wavelengths = [0.443, 0.4825, 0.5625, 0.655, 0.865, 1.61, 2.2]
IF raster.NBANDS GE 7 THEN raster.WAVELENGTH = landSat8Wavelengths[0:6]
IF raster.NBANDS GE 5 THEN raster.WAVELENGTH = landSat8Wavelengths[0:4]
```

用途：
- 如果成功补充波长，则可以直接使用 `ENVISpectralIndexRaster(raster, 'ndvi')` 自动选择 Red / NIR 波段。
- 如果仍然无法设置，则降级到 **手动 NDVI 计算**。

### 2. NDVI 计算策略

NDVI 定义：

\[
\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}}
\]

代码实现分两种情况：

#### 2.1 有波长信息（优先方式）

```idl
ndvi = ENVISpectralIndexRaster(raster, 'ndvi')
```

特性：
- ENVI 根据波长自动选择 Red / NIR 波段
- 返回虚拟栅格对象（不生成物理文件）

#### 2.2 无波长信息（手动 BandMath）

根据波段数自动判断数据类型：

- **GF1（4 波段）**  
  - Red: `b3`  
  - NIR: `b4`
  - 实现：

    ```idl
    ndvi = ENVIPixelwiseBandMathRaster(raster, $
      '(FLOAT(b4)-FLOAT(b3))/(FLOAT(b4)+FLOAT(b3))')
    ```

- **Landsat（≥5 波段）**  
  - Red: `b4`  
  - NIR: `b5`
  - 实现：

    ```idl
    ndvi = ENVIPixelwiseBandMathRaster(raster, $
      '(FLOAT(b5)-FLOAT(b4))/(FLOAT(b5)+FLOAT(b4))')
    ```

> 特别说明：  
> 这里显式使用 `FLOAT(...)`，避免整数除法导致 NDVI 结果变成 0 / 1 / 大整数，从而无法正确分级。

### 3. NDVI 值范围检查与限制

#### 3.1 诊断用的范围检查

为了方便调试和验证，代码会在中心区域采样并打印：

- NDVI 最小值
- NDVI 最大值
- NDVI 平均值

用于判断：
- NDVI 是否在合理范围内（大致 \[-1, 1]）
- 是否存在严重偏移或异常值

#### 3.2 将 NDVI 限制在 \[-1, 1]

考虑到噪声、异常值和整数除法等问题，代码使用 BandMath 对 NDVI 做“截断”：

```idl
ndvi_limited = ENVIPixelwiseBandMathRaster(ndvi, $
  '(b1 LT -1)*(-1) + (b1 GT 1)*1 + (b1 GE -1 AND b1 LE 1)*b1')
```

逻辑解释：
- 若 NDVI < -1，则设为 -1
- 若 NDVI > 1，则设为 1
- 若 -1 ≤ NDVI ≤ 1，则保持原值不变

这样可以保证后续颜色分片的输入稳定在 \[-1, 1] 范围内。

### 4. 颜色分片分类（ColorSlice）

使用 ENVI 内置任务 `ColorSliceClassification`：

```idl
Task = ENVITask('ColorSliceClassification')
Task.INPUT_RASTER     = ndvi
Task.COLOR_TABLE_NAME = color_table_name
Task.DATA_MINIMUM     = 0.0
Task.DATA_MAXIMUM     = 1.0
Task.NUMBER_OF_RANGES = number_of_ranges
Task.OUTPUT_RASTER_URI = outfile
Task.Execute
```

说明：
- NDVI 经过截断后，主要应用范围为 \[0, 1]（植被区），lower-than-0 区域在很多场景可视为低植被或非植被。
- `DATA_MINIMUM=0.0, DATA_MAXIMUM=1.0`：将 0~1 按 `number_of_ranges` 均分为若干等级。
- 分类结果是一个离散值栅格，可直接用于制图或进一步统计。

### 5. 输出文件管理

输出文件名规则：

- 输入文件：`xxx.ext`
- 输出文件：`xxx + OUTPUT_EXTENSION`  
  例如：`LC08_..._MTL.xml → LC08_..._MTL_ndvi_class.dat`

在写出前会：

1. 检查目标文件是否已存在：
   ```idl
   IF FILE_TEST(outfile) THEN BEGIN
     FILE_DELETE, outfile, /QUIET, /ALLOW_NONEXISTENT
     ; 如为 .dat，同步删除 .hdr
   ENDIF
   ```
2. 若为 ENVI 格式 `.dat`，同步删除旧 `.hdr`，避免头文件与数据不一致。

## 使用步骤（UI工作流）

### 1. 启动批量工具

在 IDL / ENVI 中运行：

```idl
batch_ndvi_colorslice_UI
```

### 2. 选择数据类型

在弹出的对话框中：

- 点击 **"Yes"**：Landsat L2 数据（文件夹 + MTL）
- 点击 **"No"**：GF1 数据（单个 TIF）

### 3. 选择输入数据

- **Landsat L2：**
  - 选择包含 `*_MTL.xml` 或 `*_MTL.txt` 的数据文件夹
  - 程序自动在该目录中查找 MTL，并通过 `DATASET_NAME='Surface Reflectance'` 打开反射率数据

- **GF1：**
  - 选择多光谱 TIF 影像
  - 程序直接通过 `e.OpenRaster` 打开

### 4. 选择输出目录

- 默认输出目录为：
  `D:\FTPfiles\guangzhou\2024年\2024年第一季度\GF1处理`
- 若目录不存在，程序会提示重新选择。

### 5. 设置 NDVI 颜色分片参数

通过 ENVI Task UI 设置：
- 颜色表：`COLOR_TABLE_NAME`
- 分类数：`NUMBER_OF_RANGES`
- 是否显示结果：`DISPLAY_RESULTS`
- 输出扩展名：`OUTPUT_EXTENSION`（如 `_ndvi_class.dat`）

用户点击 **OK** 后，参数会传入 `NDVIColorSliceBatchTask` 中。

### 6. 执行批量处理

控制台会显示：
- 当前处理文件索引与名称
- NDVI 计算方式（SpectralIndex / 手动 BandMath）
- NDVI 取值范围与平均值（诊断）
- 颜色分片执行状态
- 输出结果文件名

处理结束后，会打印：

```text
批量处理完成！
结果已保存到: <输出目录>
```

## 输出结果说明

每个输入文件对应一个输出分类栅格：

- **文件名**：`原文件名 + OUTPUT_EXTENSION`  
  示例：  
  `GF1_..._MSS.tif → GF1_..._MSS_ndvi_class.dat`

- **格式**：
  - 推荐：ENVI（`.dat + .hdr`）
  - 也可扩展为 `.tif`，但需注意空间参考与元数据的完整性

- **内容**：
  - 像元值为 **分类索引**（1, 2, ..., N）
  - 每个索引对应一个 NDVI 范围（如 0.0–0.0667, 0.0667–0.1333, ...）
  - 具体色带和范围映射由 `ColorSliceClassification` 与所选颜色表决定

建议在 ENVI 中：
- 使用 **Pseudo Color** 显示分类结果
- 打开 **Layer Properties → Class Names / Colors**，查看每一类对应的 NDVI 区间

## 参数设置建议

### 1. 分类数（NUMBER_OF_RANGES）

推荐范围：
- 5–7 类：概览级别分析（粗分类）
- 10–15 类：精细 NDVI 分布分析

对于 GF1 城市植被分析，15 类可提供较细的 NDVI 梯度，有利于区分弱植被 / 中等植被 / 高覆盖植被。

### 2. 颜色表（COLOR_TABLE_NAME）

推荐颜色表：
- `CB-Greens`：单色渐变（适合突出植被覆盖度）
- `CB-RdYlGn`：红–黄–绿渐变（适合对比低 / 中 / 高 NDVI）
- `Rainbow`：全色谱渐变（视觉效果丰富，但语义性略弱）

### 3. NDVI 结果解读

经验上：
- NDVI < 0：水体 / 裸土 / 建筑等非植被区域
- 0 – 0.3：低植被覆盖
- 0.3 – 0.6：中等植被覆盖
- 0.6 – 1.0：高植被覆盖 / 茂密植被

在颜色分片时，可根据这些经验区间选择合适的类数与颜色表。

## 错误处理与日志

`NDVIColorSliceBatchTask.pro` 中广泛使用 `CATCH` 机制，并将错误统一记录到 `errMsgs` 数组。  

典型错误处理逻辑：

- 打开栅格失败 → 跳过该文件并记录错误
- 波长设置失败 → 回退到手动 BandMath
- 波段数不足 → 记录错误并跳过
- NDVI 计算失败 / 结果无效 → 记录错误并跳过
- 颜色分片失败 → 记录错误并跳过

处理结束后：

- 若 `errMsgs NE !NULL`，则使用 `XDISPLAYFILE` 弹出窗口，列出：
  - 输入文件名
  - 对应错误信息

## 常见问题与排查建议

### Q1：为什么 GF1 的结果最开始只有 0/1 两类？

**原因（已修复）：**
- 早期版本中 NDVI 计算使用的是整数运算 `(b4-b3)/(b4+b3)`，导致结果只有 0、1 或更大整数。
- 再做颜色分片时，大部分像元集中在 0 或 1，导致只有少数类别生效。

**当前版本的修复：**
- 显式使用 `FLOAT(band)`，保证 NDVI 为浮点数，范围约为 \[-1, 1]。

### Q2：为什么 NDVI 值范围会被进一步“截断”？

为了防止异常值（例如由无效像元、数据缺失引起的极端值）影响颜色分片，代码在 NDVI 计算完毕后做了一次统一限制（clip）：

- NDVI < -1 → -1
- NDVI > 1 → 1

这样可以保证 ColorSlice 的输入在合理范围内，分类更加稳定。

### Q3：Landsat / GF1 波段顺序与代码不一致怎么办？

如果发现：
- NDVI 值范围明显异常，或者
- 高 NDVI 区域出现在明显不合理的地方（如水体）

建议：
1. 在 ENVI 中分别查看各波段，确认 Red / NIR 的实际索引；
2. 修改 `NDVIColorSliceBatchTask.pro` 中对应的 `bX` 索引，使之与实际产品一致；
3. 重新 `.compile` 后测试。
