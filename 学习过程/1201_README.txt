==========================================
test_1201footprint_envitask 使用说明
==========================================

文件夹内容：
1. test_1201footprint_envitask.pro - 任务执行程序（核心处理逻辑，已整合背景值检查功能）
2. test_1201footprint_envitask.task - 任务定义文件（JSON格式）
3. test_1201footprint_envitask_ui.pro - 图形界面程序
4. README.txt - 使用说明文档（本文档）
5. 1201_栅格轮廓提取工具使用说明.md - 详细使用说明文档

==========================================
快速开始
==========================================

方法一：使用图形界面（推荐，最简单）
----------------------------------
在IDL命令行中运行：
  .compile test_1201footprint_envitask_ui
  test_1201footprint_envitask_ui

然后在弹出的对话框中：
1. Input Raster：选择输入栅格文件（推荐方式）
   - 可以从ENVI中已打开的数据列表中选择
   - 或通过浏览按钮选择TIFF文件
2. Input File URI：留空（如果已选择Input Raster）
   - 注意：Input Raster 和 Input File URI 只需要选择一个
   - 如果选择Input Raster，Input File URI会自动忽略
3. Background Value：留空（推荐，自动检测）
   - 留空时程序会自动检测NoData值
   - 只有在特殊情况下才需要手动指定
4. Output Vector URI：选择输出矢量文件路径
   - 可以浏览选择目录并输入文件名
   - 程序会自动添加.shp扩展名
5. 点击确定开始处理

处理流程：
1. 自动检查栅格背景值（显示各波段统计信息）
2. 自动确定背景值（使用NoData值或推荐值）
3. 提取栅格轮廓
4. 生成矢量文件
5. 清理资源

程序会显示每个步骤的详细进度信息和时间统计。

方法二：直接调用任务程序（适合编程调用和批量处理）
----------------------------------
在IDL命令行中：
  .compile test_1201footprint_envitask
  
  ; 方式1：使用文件路径（推荐，避免对象引用问题）
  test_1201Footprint_ENVITask, $
    input_file_uri='你的输入文件路径.tif', $
    Background_Value=!NULL, $  ; !NULL表示自动检测（推荐）
    output_vector_uri='你的输出文件路径.shp'
  
  ; 方式2：使用栅格对象
  e = envi()
  inputRaster = e.OpenRaster('你的输入文件路径.tif')
  test_1201Footprint_ENVITask, $
    input_raster=inputRaster, $
    Background_Value=!NULL, $  ; !NULL表示自动检测
    output_vector_uri='你的输出文件路径.shp'
  inputRaster.Close

特点：
- 适合在脚本中调用
- 支持批量处理多个文件
- 可以集成到其他工作流中
- 自动执行完整的处理流程（包括背景值检查）

==========================================
处理流程说明
==========================================

程序执行时会自动执行以下5个步骤，每个步骤都会显示详细的进度信息和时间统计：

步骤1：检查栅格背景值
- 显示栅格信息（尺寸、波段数、数据类型）
- 检查元数据中的NoData值
- 检查各波段统计信息（采样前1000x1000像素）
  - 最小值、最大值、平均值
  - 最常见值（可能是背景值）
  - 边界最常见值（边界通常是背景）
  - NoData值出现频率
- 显示背景值建议
典型耗时：0.08-0.10秒

步骤2：确定背景值
- 自动检测模式（推荐）：
  - 如果Background Value参数留空，自动使用检测到的NoData值
  - 如果没有NoData值，使用推荐的背景值（边界最常见值）
  - 如果都没有，使用默认值0
- 手动指定模式：
  - 如果Background Value参数有值，使用指定的值
  - 但如果指定值为0且数据有NoData值，会智能提示并优先使用NoData值
典型耗时：< 0.01秒

步骤3：提取栅格轮廓
- 自动选择最后一个波段进行处理
- 从中心区域采样数据以验证有效性
- 创建二进制掩膜（排除背景值）
- 生成分类栅格
- 验证分类结果
典型耗时：5-6秒（取决于数据大小）

步骤4：生成矢量文件
- 将分类结果转换为Shapefile
- 导出ROI类别作为矢量轮廓
- 保存到指定路径（自动创建目录）
- 验证输出文件大小
典型耗时：10-15秒（取决于数据复杂度和轮廓形状）

步骤5：清理资源
- 关闭所有中间栅格对象（分类栅格、掩膜栅格、波段子集）
- 释放内存，防止ENVI无响应
- 显示资源清理状态
典型耗时：< 0.02秒

总耗时：通常10-20秒（小文件）到1-5分钟（大文件）

==========================================
参数说明
==========================================

输入参数：

1. Input Raster（可选）
   - 类型：ENVIRaster（栅格对象）
   - 说明：可以从ENVI中已打开的数据列表中选择，或通过浏览按钮选择文件
   - 推荐：在UI中使用此参数，操作简单

2. Input File URI（可选）
   - 类型：ENVIURI（文件路径）
   - 说明：可以直接输入文件路径，无需先打开文件
   - 注意：Input Raster 和 Input File URI 只需要选择一个
   - 如果选择Input Raster，Input File URI会自动忽略

3. Background Value（可选）
   - 类型：Double（数值）
   - 默认：自动检测（推荐）
   - 说明：
     * 留空时程序会自动检测NoData值（推荐方式）
     * 如果数据有NoData值，程序会自动使用
     * 如果没有NoData值，会使用推荐的背景值
     * 只有在特殊情况下才需要手动指定

4. Output Vector URI（必需）
   - 类型：ENVIURI（文件路径）
   - 说明：输出矢量文件路径，程序会自动添加.shp扩展名

参数选择建议：
- Input Raster vs Input File URI：
  * 推荐使用 Input Raster（在UI中选择文件）
  * 如果不想先打开文件，可以使用 Input File URI
- Background Value：
  * 推荐留空（自动检测）
  * 只有在自动检测失败或需要特殊背景值时才手动指定

==========================================
常见问题
==========================================

问题1：矢量文件为空（no records）
----------------------------------
原因：背景值设置不正确，导致所有像素都被识别为背景。

解决方法：
1. 在UI对话框中，将 Background Value 留空，让程序自动检测（推荐）
2. 查看控制台输出的"步骤1：检查栅格背景值"和"背景值建议"
3. 如果自动检测失败，根据建议手动设置合适的背景值
4. 检查数据是否真的包含有效像素区域

问题2：ENVI无响应
----------------------------------
原因：资源未正确释放（已在新版本中修复）。

说明：
- 新版本已移除视图对象获取，不打开矢量文件
- 自动关闭所有栅格对象
- 如果仍出现无响应，检查是否有其他程序占用资源或数据文件损坏

问题3：处理速度慢
----------------------------------
原因：处理大文件需要时间，这是正常现象。

说明：
- 程序会显示详细的处理进度信息和每个步骤的耗时
- 处理时间取决于数据大小和复杂度
- 典型处理时间：
  * 小文件（< 5000x5000像素）：10-20秒
  * 中等文件（5000-10000像素）：20-60秒
  * 大文件（> 10000像素）：1-5分钟
- 最耗时的步骤通常是"生成矢量文件"（步骤4），这是正常现象

问题4：掩膜中没有有效像素
----------------------------------
原因：背景值设置错误，所有像素都被当作背景。

解决方法：
1. 查看"步骤1：检查栅格背景值"的输出
2. 在UI中，将 Background Value 留空，让程序自动检测
3. 根据"背景值建议"调整背景值
4. 检查数据是否真的有有效区域

问题5：输出中有乱码
----------------------------------
原因：IDL控制台的编码问题，不影响功能。

说明：
- 某些中文字符可能在IDL控制台中显示为乱码
- 这不会影响程序功能
- 输出文件路径和结果都是正确的
- 可以在GIS软件中打开生成的矢量文件验证结果

1. 自动背景值检测

3. 智能波段选择

4. 详细的处理信息

   - 显示每个步骤的耗时统计
   - 显示总处理时间
   - 显示统计信息和诊断信息
   - 帮助用户了解处理过程

5. 完善的错误处理
   - 检查掩膜和分类结果
   - 提前发现并报告问题
   - 提供详细的错误信息

6. 资源管理
   - 自动关闭所有中间对象
   - 防止内存泄漏
   - 适合批处理场景

7. 用户友好的UI
   - 可视化参数设置
   - 实时显示处理进度
   - 详细的提示信息
